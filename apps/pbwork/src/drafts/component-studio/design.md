# 组件手机舞台

状态：exploring。2026-10-17 用户批准手机壳容器方案；本轮保留 Button、BottomSheet、Toast 三类代表组件。

共享主题页的中性外壳、系统字体和紧凑工具栏。顶部只保留一层组件切换和来源/主题/模式/对比设置，手机承担类型、尺寸、状态与反馈。绑定与来源默认折叠，不占宽侧栏。

固定逻辑设备为 390×740；舒适尺寸默认不低于 68%，舞台内滚动；完整设备按舞台空间缩放；原尺寸为 100%。设备内容有自己的纵向滚动，浮层挂到独立设备 host。没有 iframe，不复制关闭、焦点、撤销、计时或手势机制。

ThemeSurface 的设备模式仅将生成 CSS 中的视口长度换为容器视口单位，手机自身声明 size container：50dvh 渲染为 50cqh，因此半屏高度取设备高度的一半。Core 解析表、digest、来源关系与正式采集值保持原样，折叠详情仍显示原始值。正式推广前需将此适配纳入正式共享预览边界。

同一手机切换主题包、包内主题或模式时保留演示状态；改变对比设备身份、组件类别可以重新创建或重置演示。双机可以比较同模式的基础/样例或当前包，以及同包的浅/深模式。每台设备有独立的状态与挂载点。

本页是带真实交互的风格草稿，无正式 Screen boundary，不产生 Evidence。正式业务采集、Target 与全量组件迁移等用户确认后再推进。
