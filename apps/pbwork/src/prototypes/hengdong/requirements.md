# 恒动原型需求

恒动是一个不依赖服务端的移动端健身、自律与记录原型。目标是让用户用较低心理负担完成“选择计划、开始训练、完成打卡、查看积累”的闭环。

## 页面范围

- 轻量账号：登录、注册；账号仅写入浏览器本地存储。
- 一级目的地：今天、计划、记录、我的。
- 二级/三级：计划详情、训练执行、计划编辑、记录详情、数据趋势、目标与提醒。

## 数据与确定性

- 预置三个训练计划和三条历史记录。
- Capture 默认日期固定为 2026-08-13，不读取网络或随机数据。
- 用户修改写入 `hengdong.*.v1` localStorage keys。
- Theme 使用已注册的 light / dark，会话偏好使用本地存储，Theme 不作为 Variant。

## 业务局部组件

- `StreakCalendar`：打卡日历，只使用 Flex 与现有 Token。
- `WeeklyActivityBars`：训练分钟趋势，只使用 Flex 与现有 Token。

不新增 PBWork Token 或 Design System 基础组件。
