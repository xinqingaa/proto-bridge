# 恒动产品设计

> 本文是恒动的产品与体验唯一基线。产品定义、信息架构、核心旅程和共享视觉语言已经确认；页面契约按旅程逐批批准。

## 本文怎么用

`design.md` 只规定用户能理解和观察到的产品结果，不规定组件、代码或布局菜谱。

- 页面进入正式调整前，先批准一份最小页面契约：唯一职责、首屏焦点、阅读顺序、热区结果、关键状态、跨页分工和验收信号。
- 页面契约默认由 Agent 起草；用户可以直接给出决策，也可以授权 Agent 在既定产品边界内闭合。
- 未批准页面不是任意发挥的空白。允许保留现有草稿，但不得把它视为体验已经完成。
- Token、DS、Evidence、Registry、实现状态和 Promotion Mapping 记录在 `implementation.md`。
- 排布、字阶档位、图形形状、组件组合和不影响结果的文案微调留给实现与 Experience Gate。

## 产品定义

恒动是一款面向健身新手与重启者的低压力训练执行器：让用户在 10 秒内知道今天做什么，用一小段可完成的训练建立连续感。

它优先解决三个连续问题：难开始、执行中容易退出、完成后感受不到积累。它不是课程内容平台，也不是专业运动数据工具。

### 用户与情境

- 刚开始锻炼、尚未形成固定训练方式的人；
- 停练一段时间，希望低门槛重新开始的人；
- 只剩 5–20 分钟，希望马上知道做什么的人；
- 正式训练做不完，但仍希望保留真实活动记录的人。

### 产品承诺

用户每次打开恒动，都能明确看见一个最值得做的下一步；完成后，结果立即进入可见的连续记录。

### 设计原则

1. **先行动，再管理**：先给可执行动作，不先要求用户整理计划或数据。
2. **一次只强调一个决定**：同屏只有一条主路径，同一动作可以有多个热区。
3. **完成比完美重要**：允许快速记录和提前结束，不用失败式语言惩罚用户。
4. **状态必须连续**：训练、记录、计划和进度使用同一份事实，操作结果必须可见。
5. **克制但不空洞**：用信息层级、留白、节奏和语义颜色建立设计感。

### 非目标

- 不接入服务端、社交、排行榜、教练或社区；
- 不提供真实支付、会员、课程视频和器械连接；
- 不做营养、体重、睡眠等综合健康管理；
- 不追求专业训练负荷、心率区间或医疗建议；
- 不用连续天数警告、羞耻文案或大量徽章制造压力。

## 核心对象

| 对象     | 作用                 | 关键状态                                   |
| -------- | -------------------- | ------------------------------------------ |
| 用户     | 保存轻量身份与偏好   | 未登录、已登录                             |
| 计划     | 组织一组可执行动作   | 推荐、自建；未采用、当前使用、已停用       |
| 训练会话 | 表示一次正式训练过程 | 未开始、进行中、暂停、完成、提前结束、放弃 |
| 活动记录 | 形成进度的事实来源   | 正式训练、快速记录；可查看、可删除         |
| 每周目标 | 提供温和的节奏参照   | 目标次数、已完成活动次数                   |
| 提醒偏好 | 决定提醒是否启用     | 关闭、开启并设定时间                       |

一个用户只有一个当前计划。完成或提前保存训练会话后生成活动记录；快速记录不依赖计划，也生成同类活动记录。今天与进度都从活动记录派生结果。每周目标统计正式训练和快速记录，不只统计计划训练。

## 信息架构

### 根导航

底部导航始终只有三个根目的地：

| 页面 | 唯一职责             | 明确不承载                       |
| ---- | -------------------- | -------------------------------- |
| 今天 | 决定并完成下一次行动 | 完整计划管理、历史分析、账户表单 |
| 计划 | 选择与调整以后做什么 | 今日执行状态、历史趋势           |
| 进度 | 理解一段时间的活动节奏 | 完整记录管理、计划编辑、训练执行 |

设置是全局工具，不是一级目的地。今天页进入设置；计划页右上角用于新建计划，进度页右上角用于筛选。

### 页面地图与设计状态

产品基线已批准；页面契约按旅程增量推进。

| 页面       | 存在的理由                   | 页面设计状态 |
| ---------- | ---------------------------- | ------------ |
| 今天       | 提供最明确的下一步           | approved     |
| 训练执行   | 专注完成一次训练             | approved     |
| 训练总结   | 确认结果并形成反馈           | approved     |
| 活动记录   | 查看与管理完整活动历史       | approved     |
| 计划       | 管理当前与候选计划           | pending      |
| 计划详情   | 判断是否采用、开始或编辑计划 | pending      |
| 进度       | 查看周期结果与活动节奏       | approved     |
| 设置与目标 | 调整目标、提醒、主题和账户   | pending      |
| 登录       | 恢复本地身份并进入应用       | approved     |
| 注册       | 建立本地身份和初始目标       | approved     |

任务型浮层包括快速记录、计划编辑、记录详情、进度筛选、自定义日期范围和风险确认。活动记录是今天进入的二级 Screen，不是浮层，也不创造新的一级目的地。

### 导航规则

- 底部“今天 / 计划 / 进度”是唯一根级导航，不叠加另一组一级 Tab。
- 活动记录、计划详情、训练执行、训练总结和设置通过进入/返回形成任务流。
- 三个根页面只通过底部导航相互切换；页面内容不直接跳往另一个根页面。
- 页面内筛选或时间范围切换必须改变可见数据，不能只改变选中样式。
- 返回回到进入前页面和局部状态，不默认跳回今天。
- 选日期由进度页负责；今天页不承担日期筛选。

## 核心旅程

### 首次进入

恒动只提供当前设备上的单一本地身份，不模拟云端账号。登录恢复已有身份；注册建立或重建本地身份并设置初始周目标。成功后进入今天，直接看到一项可开始的短训练。校验错误靠近对应字段显示；无效输入不能提交；不追加冗长引导。

### 完成正式训练

今天给出一条主路径。进入训练后只强调当前动作和完成当前动作；暂停、中断和刷新均可恢复。全部完成或保存已完成部分后进入训练总结。保存生成活动记录，并同步更新今天与进度。

### 快速记录

用户从今天选择活动类型、时长和体感，确认后生成活动记录并立即更新本周结果。取消不写入记录。

### 采用或编辑计划

计划页先展示当前计划，再浏览推荐。筛选真实改变推荐结果；计划详情根据当前/候选状态提供不同主操作。设为当前计划后，今天的建议同步变化。

### 查看完整记录

今天展示最近五次活动；“查看全部”进入活动记录二级页。活动记录按类型切换完整列表，支持下拉刷新、加载更多、详情、删除和短时撤销。返回恢复今天的局部状态，不切换根 Tab。

### 查看进度

周、月、年范围驱动摘要、节奏图和日期视图；自定义范围作为可选时间状态。趋势刻度和日期选择只聚焦当前时间片的简要记录，完整历史和删除由活动记录页负责。进度空态不跳往其它根页面。

## 产品级体验规则

### 热区与反馈

- 看起来能点的元素必须有可观察结果和可见反馈。
- 同一任务可以有多个热区，但结果必须一致。
- 同屏只有一个最高强调动作；热区数量不等于主路径数量。
- 内容本身的变化是成功证据；Toast 只能补充，不能成为唯一证据。
- 删除等风险操作先确认，完成后允许短时撤销。

### 分区与分割线

- 换任务的大区块使用留白，不使用上下夹线模拟容器。
- 不同任务分区之间最多一条分割线。
- 列表只使用行间分割，不再给列表描上下框。
- 环、节奏带、柱状图和日历不是列表，不用分割线夹成横条卡片。
- Card 只用于确实需要边界的恢复会话、当前计划强摘要和完成结果。

### 三类数据图形

| 图形         | 页面 | 回答的问题           | 交互职责                                 |
| ------------ | ---- | -------------------- | ---------------------------------------- |
| 七日节奏     | 今天 | 这周哪几天动过       | 查看当天记录或得到无记录说明，不筛选整页 |
| 活动分钟趋势 | 进度 | 一段时间内活动量怎样 | 待进度页契约决定                         |
| 日历         | 进度 | 哪天做了什么         | 选择日期并过滤记录                       |

只有真正承担筛选的图形才出现选中态。连续性不能只依赖颜色，还要有文字、图标或形状差异。

### 全局状态

| 状态     | 体验要求                                     |
| -------- | -------------------------------------------- |
| 加载     | 轻量占位，不闪烁完整空页面                   |
| 空       | 解释为什么为空，并给出与页面职责一致的下一步 |
| 校验错误 | 靠近字段说明原因，修正后即时消失             |
| 禁用     | 样式和行为同时表达，并保留可理解原因         |
| 保存成功 | 内容立即变化，短提示只作补充                 |
| 中断     | 保存进行中训练，再次进入优先恢复             |
| 离线     | 默认可用，不展示虚假的同步或网络错误         |

## 视觉方向

### 视觉命题

像一份清醒、克制的私人训练手账：有行动张力，但不使用高噪声竞技视觉；先看见下一步和已经完成，再看见辅助数据。

### 共享视觉语法

- **目标使用环**：今天、周目标和训练完成使用连续环表达积累和下一步。环是品牌识别，不是装饰图表。
- **过程使用序列**：动作列表、计划详情和训练中的当前/下一动作强调顺序和预期。
- **执行使用身体舞台**：训练执行以姿态、动作名称和节奏为视觉中心，降低其它界面噪声。

三种语法服务不同任务，不随机混成三套主题。今天以环为主，计划与详情以序列为主，训练以身体舞台为主，进度只沿用环和节奏语汇。

### 层级与节奏

- 页面背景保持安静，大部分内容直接排版在页面上。
- 根页面使用舒展首屏与紧凑列表的节奏对比。
- 页面级主数字与训练动作形成明确焦点；标题、正文和辅助信息稳定退阶。
- 品牌色用于选中、进度与关键路径，不大面积填满普通容器。
- 成功色只表达完成和正向变化，警示色只表达真实风险。
- 图标帮助识别操作，不作为大面积装饰。

### 动效与资产

- 动效只服务动作推进、完成确认、浮层进出和数据范围切换。
- 减少动态效果后，信息和操作结果仍然完整。
- 训练姿态第一阶段允许静态关键姿态与短促过渡；完整动作动画不在当前承诺内。

### 目标视口与可访问性

- 首要验收视口为移动端 `390 × 844`，常见窄屏不得横向溢出。
- 页面只消费一次顶部安全区域，滚动内容不被底部导航或固定操作遮挡。
- 键盘弹出时，当前字段与主操作可以滚动到可见位置。
- 可交互元素具备可读名称、完整触控区域和可见键盘焦点。
- 浅色与深色主题保持相同语义层级和对比关系。

### 内容语气

- 使用具体、短句和行动语言，例如“开始 15 分钟”“本周已完成 2 次”。
- 避免竞技命令、空泛口号和羞耻表达。
- 中断或少量完成时使用中性反馈，例如“已保存完成的 8 分钟”。
- 数字结论说明时间范围；周目标统一称“本周活动”。

## 已批准页面契约：今天

### 唯一职责与首屏焦点

今天只决定并完成下一次行动。首屏焦点是“现在做什么”，不是回看历史或管理计划。

### 阅读顺序

工具行（日期、问候、设置）→ 今日状态与周目标环 → 主行动 → 本周节奏 → 最近记录。

### 主路径与热区

- 周目标环和主按钮是同一动作的两个热区。
- 默认时开始当前计划；进行中时继续原会话；无计划时进入计划选择。
- 已完成时先表达完成结果，再练是可用的次路径，不继续高强度催促。
- 快速记录始终是次操作，打开本页连续流程。
- 环只承担当前主路径，不进入进度，也不选择日期。

### 本周节奏

- 回答七天中哪些天有活动，并给出整周累计分钟。
- 七天标记共享同一视觉基线；今天态不能通过改变标签尺寸造成错位。
- 点击有记录的一天，在今天页打开该日记录详情。
- 点击没有记录的一天，给出轻量无记录说明，不出现假选中。
- 本周节奏不提供跨根入口；完整历史从最近记录区域进入活动记录二级页。

### 最近记录

- 展示按时间倒序排列的最近五次活动，使用平面信息条，不套 Card，也不给列表描上下框。
- 点击记录在今天页打开只读详情；“查看全部”进入活动记录二级页。
- 没有最近记录时显示一句说明，不摆空卡片。

### 记录详情 Sheet

- 唯一职责是让用户快速确认“这次做了什么”，不承担编辑、删除或历史管理。
- 阅读顺序为完成结果与日期 → 活动名称与来源 → 时长、类型和体感 → 正式训练的完成内容 → 备注。
- 从有记录的节奏日或最近记录进入时，展示同一条记录；关闭后回到进入前的今天页状态。
- 正式训练显示实际完成的动作；快捷记录不伪造动作列表，活动名称和类型即为内容结论。
- 没有备注时明确说明未留下备注；长备注可以完整阅读，不遮挡关闭入口或底部导航。
- 今天页中的详情保持只读；查看完整历史和删除记录由活动记录页负责。
- 浅色与深色主题下，用户应能一眼识别日期、活动名称、时长和完成结果，且信息层级不依赖多张 Card 或连续分割线。

### 关键状态

| 状态         | 页面结果                                                 |
| ------------ | -------------------------------------------------------- |
| 默认         | 开始短训练是主路径，快速记录是次操作                     |
| 进行中       | 主路径改为继续训练，不并列开始新的                       |
| 结果待保存   | 主路径进入训练总结，不重新打开动作执行                   |
| 已完成       | 先显示完成反馈，再练降低强调                             |
| 无当前计划   | 主路径改为选择计划，快速记录仍可用                       |
| 最近为空     | 保留今天主路径，最近区域只给简短说明                     |
| 快速记录打开 | 浮层清楚显示当前步骤、返回和保存结果                     |
| 记录详情打开 | 保持今天页上下文，支持正式训练、快捷记录、无备注与长备注 |

### 与其它页面分工

- 今天决定下一次行动；计划管理以后做什么。
- 今天只查看某日记录；活动记录负责完整历史和删除，进度负责范围分析。
- 今天发起或恢复训练；训练执行和训练总结负责过程与保存。

### 可观察验收信号

- 首次进入即可指出主路径及点击后的结果。
- 点击环与点击主按钮得到同一结果。
- 点击有记录和无记录的节奏日得到两种明确结果。
- 最近记录在今天页打开详情，“查看全部”进入活动记录二级页并能返回原位置。
- 默认、进行中、完成、无计划和最近为空均可独立复现。
- 大区块之间没有连续夹线，列表没有上下描框，七天标记对齐。
- 浅色、深色及目标视口下，签名环、主次动作和阅读顺序均成立。

## 已批准页面契约：训练执行

### 唯一职责与首屏焦点

训练执行只帮助用户完成当前动作。首屏最高焦点是当前动作的关键姿态、动作名称和本次目标；总时长、动作位置和下一动作只提供上下文。

### 阅读顺序

会话上下文 → 动作进度 → 身体舞台与当前目标 → 单条动作提示 → 下一动作 → 当前主操作。

### 动作推进与反馈

- 计次动作由用户确认完成；计时动作到零后先明确完成，再进入下一动作。
- 运行中只强调完成当前动作；暂停是次操作。
- 暂停后计时停止，舞台明确降静，唯一主操作改为继续训练。
- 第二个动作起可以返回上一个动作；返回后该动作重新成为未完成。
- 动作进度和下一动作默认只表达位置与预期，不伪装成可跳转控件。
- 最后一个动作完成后进入训练总结，不直接生成活动记录。

### 退出与恢复

- 退出入口打开本次训练的结果选择，不静默丢失进度。
- 继续训练关闭选择并保留当前状态。
- 稍后继续保留会话并返回今天；再次进入时以暂停状态恢复，计时不在后台继续。
- 至少完成一个动作后可以保存已完成部分，并进入部分完成总结。
- 放弃本次清除会话且不生成活动记录。
- 刷新、中断和重新进入均恢复同一动作、完成进度和累计时间。

### 关键状态

| 状态         | 页面结果                                               |
| ------------ | ------------------------------------------------------ |
| 计时进行中   | 展示剩余时间，到零后给出明确完成反馈                   |
| 计次进行中   | 展示目标次数，由用户确认完成                           |
| 暂停         | 计时停止，舞台降静，继续训练成为唯一主操作             |
| 动作切换     | 已完成动作与下一动作变化可见                           |
| 中断恢复     | 进度和时间保留，以暂停状态等待用户继续                 |
| 退出选择     | 根据是否已有完成动作提供保留、部分保存或放弃结果       |
| 最后动作     | 主操作改为完成训练，结果进入训练总结                   |
| 无效会话     | 解释无法恢复并提供回到今天的明确结果，不显示空白舞台   |

### 身体舞台与姿态降级

- 身体舞台使用静态关键姿态和安静的呼吸轨迹，姿态不承担唯一教学职责，文字提示始终保留。
- 默认计划中的主要动作使用对应姿态；没有准确姿态的自建动作使用中性活动姿态，不展示错误动作。
- 动作切换只使用短促过渡；减少动态效果时直接切换，信息和操作结果不变。
- 训练页不使用完整动作列表、大面积 Card、目标环计时器或竞技式视觉替代身体舞台。

### 与其它页面分工

- 今天负责开始或恢复训练；训练执行不管理计划、历史和周目标。
- 训练执行只保存会话进度；训练总结负责确认并生成活动记录。
- 计划详情可以发起训练，但进入后遵守同一会话与返回规则。

### 可观察验收信号

- 用户在任一动作都能立即指出当前目标和唯一下一步。
- 暂停前后计时、舞台和主操作同时变化。
- 稍后继续返回今天后仍能恢复同一动作，且后台时间没有增长。
- 零完成与已有完成的退出选择不同，放弃不生成记录。
- 完成最后动作和保存已完成部分分别进入完整与部分训练总结。
- 浅色、深色、目标视口和窄屏下身体舞台、提示与底部操作互不遮挡。

## 已批准页面契约：训练总结

### 唯一职责与首屏焦点

训练总结只确认即将保存的训练结果，并收集一次轻量体感。首屏最高焦点是实际完成结果，不是表单。

### 阅读顺序

完成结果 → 实际时长、计划与动作数 → 保存后的本周影响 → 完成体感 → 可选备注 → 保存并回到今天。

### 结果与保存

- 完整完成使用“这次训练完成了”，展示全部动作结果。
- 部分完成使用“已完成一部分”，中性说明实际分钟和动作数，不使用失败或补偿文案。
- 保存前的周目标明确使用“保存后，本周将达到”，不把未提交结果说成已记录。
- 体感初始不替用户选择；选择轻松、刚好或吃力后才能保存。
- 备注可以为空；保存只生成一条活动记录，重复触发不能重复写入。
- 保存成功后清除训练会话并回到今天；周目标、本周节奏和最近记录立即更新。
- 未保存时刷新保留体感和备注；离开不能静默丢弃待保存结果。

### 关键状态

| 状态         | 页面结果                                               |
| ------------ | ------------------------------------------------------ |
| 完整完成     | 明确显示全部动作、实际时长和保存后的周目标             |
| 部分完成     | 明确显示实际完成数量和时长，语气中性                   |
| 未选体感     | 保存不可用并说明还需选择本次体感                       |
| 编辑备注     | 键盘出现后当前字段和保存操作仍可到达                   |
| 保存进行中   | 阻止重复提交，保留当前结果和操作文案                   |
| 保存成功     | 只写入一条记录，清除会话并回到今天的已完成状态         |
| 无有效会话   | 说明结果无法恢复并提供回到今天的明确结果               |

### 与其它页面分工

- 训练执行决定实际完成内容；训练总结不修改动作完成顺序。
- 训练总结生成活动记录；今天展示即时结果，活动记录负责完整历史与删除，进度只派生周期结果。
- 总结页不承担再次训练、计划编辑或周目标设置。

### 可观察验收信号

- 完整与部分完成一眼可区分，但都使用无压力语言。
- 未选择体感不能保存，选择后主操作立即可用。
- 保存前后“将达到”和“已完成”的时间语义不混淆。
- 保存后今天的环、节奏和最近记录同步变化，且没有重复记录。
- 长备注、键盘、浅色、深色与窄屏不遮挡结果或保存操作。

## 已批准页面契约：活动记录

### 唯一职责与首屏焦点

活动记录只负责完整回看和管理活动事实。首屏焦点是按时间倒序排列的记录时间线，不承担周期表现分析。

### 阅读顺序

返回与页面标题 → 活动类型二级 Tab → 当前分类的月份与日期分组 → 活动记录 → 记录详情与管理结果。

### 分类、刷新与分页

- “全部 / 训练 / 步行 / 拉伸 / 自由活动”使用二级页内 Tab，每项拥有完整列表视图。
- 点击或横滑切换分类；每个分类保留自己的滚动位置和分页状态。
- 每个列表支持顶部下拉刷新和触底加载更多；刷新重新读取持久化记录并更新排序、数量和当前内容。
- 记录按月份、日期倒序分组，同一天的多条记录共享日期上下文。
- 月份入口只负责快速定位历史，不生成统计结论。

### 详情与删除

- 点击记录打开详情，内容结构与今天页详情一致。
- 活动记录页详情允许删除；删除前确认，成功后列表、今天和进度同步更新，并允许短时撤销。
- 从今天进入后，返回恢复今天的局部状态和滚动位置，不切换根 Tab。

### 关键状态

| 状态         | 页面结果                                                   |
| ------------ | ---------------------------------------------------------- |
| 默认         | 全部分类展示完整时间线                                     |
| 分类切换     | 内容水平切换，保留各分类滚动位置                           |
| 刷新中       | 顶部显示刷新反馈，已有内容不被空白替换                     |
| 加载更多     | 尾部追加更早记录，避免重复请求                             |
| 分类为空     | 保留分类定位，说明当前类型没有记录                         |
| 完全为空     | 说明活动完成或快速记录后会出现在这里，不跳往其它根页面     |
| 详情打开     | 保持时间线上下文，支持正式训练、快捷记录、无备注和长备注   |
| 删除确认     | 明确说明记录和派生结果会同步变化                           |
| 删除后撤销   | 原记录恢复到正确日期和分类位置                             |

### 与其它页面分工

- 今天展示最近五次和只读详情；活动记录展示全部历史并负责删除。
- 进度解释时间范围内的节奏，只展示当前时间焦点的简要记录。
- 活动记录不管理计划、训练会话、周目标或趋势图。

### 可观察验收信号

- 今天“查看全部”进入活动记录，返回后今天原位置和状态不丢失。
- 五个分类可点击和横滑，内容、数量、空态和滚动位置真实变化。
- 下拉刷新和加载更多不误触 Tab，横滑不触发刷新。
- 删除与撤销后，今天、活动记录和进度使用同一份事实。
- 浅色、深色、目标视口和窄屏下，日期刻度、记录主信息和详情互不遮挡。

## 已批准页面契约：进度

### 唯一职责与首屏焦点

进度只帮助用户理解一段时间内的活动节奏。首屏焦点是当前周期的事实结论和节奏分布，不是完整历史列表或专业训练评分。

### 阅读顺序

页面标题与筛选 → 本周 / 本月 / 本年一级 Tab → 当前日期范围 → 周期结论 → 活动节奏 → 日期视图 → 当前时间焦点的简要记录。

### 周期与自定义范围

- 本周、本月、本年各自拥有完整内容面板，可点击或横滑切换，并使用一致的水平过渡。
- 周期前后浏览使用明确箭头，不与 Tab 横滑竞争；当前周期之后的范围不可进入。
- 自定义范围从日期操作进入；应用后形成可返回的临时“自定义”周期状态，不长期占用默认 Tab。
- 自定义范围不能包含未来日期，最长一年；取消或非法输入不改变当前结果。
- 活动类型筛选通过任务型浮层完成，不增加更深一层 Tab。

### 节奏、日期与记录

- 周以日、月以周、年以月表达同一套活动节奏语法；自定义范围按跨度选择可读粒度。
- 周期摘要统一说明活动次数、累计分钟和活动天数；周范围额外说明当前周目标。
- 点击趋势刻度聚焦一个时间片；点击日期聚焦精确日期，两者互斥且都更新当前选择说明。
- 当前焦点只展示简要记录并允许只读查看详情；完整历史和删除由活动记录页负责。
- 活动类型筛选同步影响摘要、节奏、日期标记和当前选择。

### 关键状态

| 状态       | 页面结果                                                   |
| ---------- | ---------------------------------------------------------- |
| 本周       | 目标、七日节奏和日期焦点成立                               |
| 本月       | 按周节奏和完整月历成立                                     |
| 本年       | 十二个月节奏和月份焦点成立                                 |
| 自定义     | 明确显示起止日期和对应粒度                                 |
| 历史周期   | 范围、摘要、图形和日期同步变化                             |
| 活动筛选   | 所有可见派生数据同步更新                                   |
| 时间聚焦   | 趋势或日期只有一个选中来源，并显示对应简要记录             |
| 无数据     | 保留周期选择并解释当前范围无记录，不跳往其它根页面         |
| 详情打开   | 保持进度上下文，只读展示记录事实                           |

### 与其它页面分工

- 今天决定下一次行动并展示最近五次，不提供进入进度的内容入口。
- 活动记录负责完整历史、刷新、分页和删除；进度不复制这些管理职责。
- 进度不编辑计划、训练会话、目标或活动记录。

### 可观察验收信号

- 三个默认周期可点击和横滑，选中态、面板方向与数据同步变化。
- 周、月、年和自定义范围呈现不同粒度，但保持同一视觉语法和阅读顺序。
- 纵滚、Tab 横滑、日期操作和刷新互不误触；减少动态效果时信息完整。
- 保存、删除或撤销记录后，摘要、节奏和日期标记立即与共享事实一致。
- 浅色、深色、目标视口和窄屏下，首屏结论、节奏图、日期视图和底栏互不遮挡。

## 已批准页面契约：登录

### 唯一职责与首屏焦点

登录只验证当前设备已有的本地身份并恢复使用。首屏焦点是账号、密码和“进入恒动”，不承担注册资料、目标管理或云端账号说明。

### 阅读顺序

品牌起步环与简短欢迎语 → 账号 → 密码 → 主操作 → 建立或重建本地身份入口 → 本地数据说明。

### 主路径与交互

- 密码默认隐藏，可通过眼睛图标显示或隐藏，切换不改变输入值和焦点顺序。
- 当前设备默认保持登录直到用户在设置中退出，不提供没有实际效果的“保留登录状态”。
- 空字段错误靠近对应字段；账号或密码不匹配使用统一说明，不透露具体错误项。
- 修改字段后对应错误即时消失；本地校验不伪造网络等待或网络失败。
- 登录与注册是同级入口页面，互相切换使用替换，不形成返回循环；成功登录后替换为今天。
- 正式界面不展示演示密码，自动场景通过确定输入完成登录。

### 关键状态

| 状态         | 页面结果                                               |
| ------------ | ------------------------------------------------------ |
| 默认         | 空表单，进入恒动为唯一最高强调动作                     |
| 必填错误     | 账号与密码分别说明需要填写                             |
| 凭据错误     | 密码字段附近显示统一的账号或密码错误                   |
| 密码可见     | 图标和可访问名称同步改变，输入内容不丢失               |
| 无本地身份   | 不展示不可用登录表单，主路径改为建立本地身份           |

### 与其它页面分工

- 注册建立或重建本地身份并设置初始周目标；登录不编辑身份信息。
- 设置负责退出登录、目标、提醒和重置；退出不删除设备上的训练事实。
- 今天负责登录后的下一步行动；登录页不预演计划、训练或进度内容。

### 可观察验收信号

- 空字段、错误凭据和密码显隐具有可见且可访问的即时反馈。
- 登录成功进入今天，浏览器返回不重新形成登录与注册循环。
- 窄屏和键盘弹出时，当前字段、错误信息与主操作均可滚动到可见位置。
- 桌面视口保持单列有限宽度，不让表单横跨页面。

## 已批准页面契约：注册

### 唯一职责与首屏焦点

注册只建立当前设备的本地身份与初始周目标。首屏焦点是完成最少必要信息并开始使用，不扩展为多步 onboarding。

### 阅读顺序

本地身份说明 → 称呼 → 账号 → 密码 → 每周活动目标 → 本地数据边界 → 创建并开始 → 返回登录。

### 主路径与交互

- 称呼、账号和密码分别校验；账号去除首尾空格并规范为小写，仅接受 3–20 位字母、数字或下划线。
- 密码至少 6 位，默认隐藏并支持显示或隐藏。
- 初始目标在同一表单选择每周 2、3、4 或 5 次，默认每周 3 次，不拆为第三个页面。
- 本地存储说明是事实说明，不要求勾选伪协议。
- 首次建立身份后直接进入今天；已有身份时提交先确认替换登录凭据，计划、活动记录和其它设备数据继续保留。
- 返回登录与成功进入今天均使用替换导航，并保持当前主题。

### 关键状态

| 状态         | 页面结果                                               |
| ------------ | ------------------------------------------------------ |
| 首次建立     | 展示完整表单和默认每周 3 次目标                        |
| 字段错误     | 每个无效字段就近说明原因                               |
| 密码可见     | 图标、可访问名称和输入类型同步改变                     |
| 替换身份     | 提交前明确说明旧凭据失效、训练数据继续保留             |
| 替换确认     | 使用短确认对话框，不把风险说明藏在 Toast               |

### 与其它页面分工

- 登录只验证已有身份；注册不承担日常资料编辑或找回密码。
- 设置继续负责周目标的后续调整、退出和重置。
- 当前原型不提供多账号、云端同步、验证码、邮箱验证、用户协议或安全恢复承诺。

### 可观察验收信号

- 创建身份会同时保存规范化账号、称呼和周目标，并进入今天显示新称呼。
- 已有身份替换必须经过确认；取消确认不修改任何本地事实。
- 登录与注册往返不会堆叠历史，退出后训练记录仍可再次登录查看。
- 浅色、深色、目标视口、窄屏和桌面下，表单、说明、错误与确认层完整可读。

## 待定页面与推进顺序

其余页面按用户旅程逐批补契约，不提前规定构图：

1. 计划 + 计划详情；
2. 设置与目标；

## 已否决方向

- 四个底部 Tab；
- 今天页内容直接跳往计划或进度根页面；
- 计划页“我的计划 / 推荐”主标签；
- 记录页“日历 / 训练记录”主标签；
- 统计作为独立深层页面；
- 每段内容一个 Card；
- 用分割线给区块描边；
- 静态控件模拟交互；
- 环只作装饰；
- 今天页预演完整动作清单或人体舞台；
- 今天节奏带承担进度日期筛选；

- 完成训练或快速记录后，今天与进度同步变化；
- 中断训练可以恢复，删除记录可以撤销；
- 任一根页面首屏只有一个最高视觉焦点；
- 浅色与深色主题保持层级、对比度和语义一致；
- 登录、选择计划、完成训练、快速记录、查看进度和调整目标最终形成完整可演示闭环。
