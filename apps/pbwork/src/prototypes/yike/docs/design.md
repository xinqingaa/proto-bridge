## 产品定义

**一刻**是一款只在本机运行的专注与习惯小工具：打开就能开始一段专注，一次点击完成今天的打卡，回头能看见时间花在了哪里。

它优先解决三件事：开始专注的门槛高、小习惯坚持不下来、过后说不清时间去了哪里。它不是任务管理工具，也不是数据分析工具。

### 用户与情境

- 用番茄钟切分工作、学习时间的上班族、学生与备考人群；
- 想坚持几个小习惯（喝水、阅读、运动、早睡），但不想被复杂的习惯工具打扰的人；
- 偶尔需要正计时计圈，或倒计时煮面、做平板支撑的人；
- 用户本人的日常使用。

### 产品承诺

任何时候打开一刻，首屏都能直接开始一段专注；完成的专注和打卡立即出现在回顾里。

### 设计原则

1. **打开即用**：没有登录、引导页或空白配置页；默认配置就能用。
2. **数字是主角**：计时数字是专注页唯一焦点，其它信息退为上下文。
3. **一次点击完成**：打卡一次点击完成，并且可以撤销。
4. **中断不丢失**：刷新、切走或误关后，计时与会话都能恢复，时间不会在后台偷偷流逝。
5. **安静克制**：不用连续天数警告、徽章墙或羞耻文案制造压力。
6. **像一件物件**：每种表盘都像桌上一件真实的计时器，而不是一块仪表盘。

### 非目标

- 不做登录、账号、云同步、服务端或社交；
- 不做真实系统通知与后台计时；提示音、振动和提醒只声明为交互意图，原型中以可见反馈代替；
- 不做白噪音、任务管理、日历同步或数据分析报表；
- 不做补卡：打卡只针对今天；
- 不做连续天数、排行榜或成就徽章。

## 核心对象

| 对象 | 作用 | 关键状态 |
| --- | --- | --- |
| 专注会话 | 一次番茄、正计时或倒计时 | 未开始、进行中、暂停、休息中、本轮完成、到点、已放弃、中断待恢复 |
| 番茄配置 | 专注时长、短休、长休、长休间隔 | 默认 25 / 5 / 15 分钟、每 4 轮长休 |
| 计圈 | 正计时中的分段 | 每圈用时、累计用时；只属于当前会话 |
| 专注记录 | 回顾的事实来源之一 | 开始时间、类型、分钟数；可在回顾中查看 |
| 习惯 | 名称、图标、频率（每天，或每周 N 次）、可选提醒时间 | 进行中、已归档 |
| 打卡记录 | 某天完成某个习惯，回顾的另一个事实来源 | 已打卡、已撤销 |
| 偏好 | 表盘、模式、番茄配置、提示音 | 立即生效并保存在本机 |

关系与规则：

- 完成的番茄轮、提前结束的番茄轮、停止的正计时和到点的倒计时各生成一条专注记录；放弃和取消不生成记录。
- 提前结束或停止时不足 1 分钟视为放弃，并在确认中说明不会记录。
- 计圈只在当前会话中显示，记录只保存总时长。
- 休息不生成专注记录。
- 打卡只针对今天；每周 N 次的习惯达到 N 次后仍可继续打卡，进度显示为已完成。
- 归档的习惯从打卡页隐藏，记录保留，可以恢复；删除会同时删除其打卡记录。
- 「今天已专注」和回顾全部从专注记录与打卡记录派生，不另存统计值。

## 信息架构

### 根导航

底部导航始终只有三个根目的地，标签只用文字：

| 页面 | 唯一职责 | 明确不承载 |
| --- | --- | --- |
| 专注 | 开始并完成一段专注 | 习惯管理、历史分析 |
| 打卡 | 完成今天的习惯 | 计时、长期统计 |
| 回顾 | 看最近一段时间花在了哪里 | 编辑记录、管理习惯 |

正计时和倒计时是专注页内的模式，不单独占一个 Tab。设置是全局工具，不是根目的地，只从专注页工具行进入。

### 页面地图

| 页面 | 存在的理由 | 进入方式 |
| --- | --- | --- |
| 启动页 | 冷启动时建立品牌识别，然后让路 | 冷启动；结束后替换为专注页，返回不会回到启动页 |
| 专注 | 开始并完成一段专注 | 根 Tab；冷启动默认页 |
| 打卡 | 完成今天的习惯 | 根 Tab |
| 回顾 | 看一周或一个月的专注与打卡 | 根 Tab |
| 习惯详情 | 看一个习惯一年来的坚持情况并管理它 | 打卡页点习惯名称区域 |
| 新建或编辑习惯 | 用最少步骤建立或修改一个习惯 | 打卡页右上角新建；详情页编辑；以 FlowSheet 呈现 |
| 设置 | 选择表盘，调整模式、番茄时长和提示音 | 专注页工具行 |

任务型浮层：放弃确认、中断恢复、删除习惯确认、重置数据确认、时长选择、已归档习惯列表、打卡撤销提示。

### 导航规则

- 三个根页面只通过底部导航互相切换，内容区不跨根跳转。
- 习惯详情与设置是压栈页面，返回回到进入前页面和局部状态。
- FlowSheet 关闭只丢弃未保存输入；保存后回到来源页并显示结果。
- 回顾页的周、月切换和前后翻页改变可见数据，不只改变选中样式。
- 计时进行中切换 Tab 不中断计时；回到专注页看到同一会话。

## 核心旅程

### 打开即专注

冷启动显示当前表盘的品牌静帧，随后替换为专注页的「番茄 · 待开始」。一次点击「开始专注」进入进行中。进行中可以暂停与继续；暂停时表盘图形明确静止。一轮结束后显示「本轮完成」，用户开始休息或跳过休息进入下一轮；第 4 轮后进入长休。

### 提前结束与放弃

进行中的次操作是「放弃本轮」，确认后不生成记录；确认中说明已专注的分钟不会记录，并给出保留的办法。暂停时的次操作是「提前结束并记录」，生成实际分钟的记录。

### 正计时与计圈

正计时从零开始，主操作为暂停与继续，次操作为计圈。计圈列表把当前圈放在最上方，已完成的圈显示单圈与累计用时。停止后生成总时长的记录。

### 倒计时

用户从预设时长中选择，或自定义时长，然后开始。进行中可以暂停或取消；到点后给出明确的可见反馈（提示音开启时同时声明提示音意图），用户选择完成或再计 1 分钟。

### 中断后恢复

刷新、切走或误关后再次打开，专注页以暂停状态呈现原会话，并打开恢复面板：从原处继续、结束并记录已专注的分钟，或放弃。时间在中断期间冻结，不在后台流逝。

### 打卡与撤销

打卡页列出进行中的习惯，每个习惯显示本周七天的孔位与今天的打卡按钮。点一次完成今天的打卡，孔位与本周进度立即变化，并出现带「撤销」的短提示；再次点已完成的按钮取消今天的打卡，同样可以撤销。全部完成时页面给出一句安静的完成说明。

### 新建与管理习惯

打卡页右上角打开新建 FlowSheet：名称、图标、频率（每天或每周 N 次）、可选提醒时间。名称为空不能保存，错误就近说明。保存后回到打卡页，新习惯出现在列表中。习惯详情显示本周、本月、一年的完成次数与一年热力图，可以编辑、归档或删除；删除先确认。

### 回顾

回顾默认显示本周：专注总时长、专注次数、打卡次数，每天的专注分钟和按类型的分布。选中某天显示当天的专注记录与完成的习惯。切到月视图显示整月日历，每天的深浅表示专注分钟。没有记录时说明原因并提供回到专注的入口。

### 切换表盘与模式

设置页的表盘选择以三张小预览呈现三种表盘各自的样子；选中后整个一刻立即切换配色与签名图形，打卡页布局不变。模式在浅色、深色与跟随系统之间切换，与表盘独立。

## 产品级体验规则

### 热区与反馈

- 看起来能点的元素必须有可观察结果和可见反馈；表盘图形只显示时间，不可拖动或点按设置时长。
- 同屏只有一个最高强调动作：专注页是开始、暂停或继续；打卡页没有全局主操作，每个习惯的打卡按钮各自独立。
- 打卡行中，名称区域进入详情，打卡按钮完成打卡，两个热区结果不同且互不误触。
- 内容本身的变化是成功证据，短提示只作补充。
- 放弃、删除、重置先确认；打卡变化以短时撤销代替确认。

### 计时规则

- 计时数字使用等宽数字，跳动时不左右抖动。
- 剩余时间同时由数字和表盘图形表达，两者始终一致：机械的扇面、水位的水面、日影的影子都按剩余比例变化；机械表盘按真实 60 分钟刻度读数。
- 暂停、休息、本轮完成、到点各有可区分的表达，不只依赖颜色：说明文字随状态变化，图形静止或变浅。
- 休息使用降低强调的同一图形，不引入第二个品牌色。

### 全局状态

| 状态 | 体验要求 |
| --- | --- |
| 空 | 说明为什么为空，并给出与页面职责一致的下一步 |
| 校验错误 | 靠近字段说明原因，修正后即时消失 |
| 保存成功 | 内容立即变化，短提示只作补充 |
| 中断 | 保存会话，再次进入优先恢复 |
| 离线 | 默认可用，不展示同步或网络错误 |

## 视觉方向

### 视觉命题

一刻像桌上一件安静的计时器物件。三种表盘是三件不同的物件：拧发条的厨房计时器、一杯慢慢喝掉的水、午后纸面上移动的日影。用户选择自己喜欢的那一件，整个 App 随之换上它的材质和语气。

### 三套表盘主题

| 表盘 | 物件与命题 | 品牌色与底色 | 签名图形 | 打卡标记 |
| --- | --- | --- | --- | --- |
| 机械 | 拧发条的厨房计时器，剩余时间是一块会变小的扇面 | 柿子色；哑光瓷白底 | 带 60 分钟刻度的扇面表盘 | 在本周那一格打一个孔 |
| 水位 | 一杯慢慢喝掉的水，剩余时间是缓慢下降的水平面 | 苔绿；石灰底 | 数字半浸在水中，水下部分反色 | 往本周那一格滴一滴水 |
| 日影 | 午后纸面上的日晷，剩余时间是一道慢慢扫过的软影 | 靛蓝；暖灰纸底 | 纸面日晷上的软影 | 盖一枚刻着习惯首字的印章 |

三套主题统一使用 PBWork 默认字体，字体不随表盘变化。三套主题的取值以 `drafts/yike/styles/` 风格草稿为参照，正式取值在主题包中定义并通过对比度校验。

### 共享视觉语法

- **结构不随表盘变化**：信息架构、页面结构、阅读顺序、交互与状态在三套主题中完全一致；表盘只改变配色、签名图形、打卡标记和数据图形的笔触。
- **专注页是一件物件**：签名图形是专注页唯一的大物件，数字在物件内部；模式、轮次和操作退为物件周围的上下文。
- **打卡页是一张打孔卡**：每个习惯一行，周历孔位与右侧打卡按钮对齐同一条星期表头；三套主题只换孔位与按钮的标记。
- **数据图形沿用物件语汇**：回顾周视图的每日柱、月视图日历和习惯一年热力图都使用当前表盘的语汇：机械是按番茄块堆叠的柱与深浅色块，水位是试管与小杯水位，日影是墨线软影与靛蓝印点。
- **工具页安静**：设置、习惯详情和新建习惯使用分组列表与表单，不出现签名图形，只在表盘选择中出现三张预览。

### 层级与节奏

- 页面背景安静，大部分内容直接排在页面上；卡片只用于打孔卡行、分组列表和当天记录。
- 品牌色只用于主操作、进度、今天、选中和签名图形，不大面积铺满普通容器。
- 危险操作使用一个独立的危险色，只出现在删除、重置和放弃的确认中。
- 图标只帮助识别习惯类型和操作，线性、细笔画，不作装饰。
- 底部导航只用文字标签，当前项用墨色加强；不使用图标或胶囊高亮。

### 动效、声音与资产

- 进行中：机械扇面连续缩小；水面以很慢的波纹下降；日影缓慢扫过纸面。暂停时三者完全静止。
- 本轮完成与到点：一次短促的完成反馈；提示音开启时声明提示音意图，原型中以可见反馈代替。
- 打卡：机械打孔、水滴落下、印章盖下各有一次短反馈；撤销反向恢复。
- 减少动态效果时去掉波纹、扫动和打卡动画，直接切换到结果状态，信息与操作结果完整。
- 签名图形在正式实现中以 SVG 或绘制实现，不依赖位图；需要循环动效的水面波纹单独声明资产与降级。

### 目标视口与可访问性

- 首要验收视口为 `390 × 844`，常见窄屏不得横向溢出。
- 页面只消费一次顶部安全区域，内容不被底部导航遮挡。
- 键盘弹出时，当前字段与保存操作可以滚动到可见位置。
- 可交互元素具备可读名称、完整触控区域和可见键盘焦点；签名图形提供与数字一致的可读描述。
- 三套主题的浅色与深色都保持相同的语义层级和对比关系；日影深色中的影子改为浅色光晕，保证可读。

### 内容语气

- 短句、具体、安静，例如「今天已专注 50 分钟」「第 3 轮已完成 · 休息一下」「从一个小习惯开始」。
- 不催促、不评判：中断与放弃使用中性说明，例如「已经专注的 12 分钟不会被记录」。
- 数字结论说明时间范围，例如「本周」「10月14日 周三」。

## 品牌层缺口

正式页面只能使用已注册的 Token，而 PBWork 目前只有全局的浅色与深色两套 Theme，无法表达三套表盘主题的品牌色与组件形态。用户的处理方式：

- 方案 A（主路径）：等待平台升级第 2 步的原型主题包，并要求它支持「一个原型、多套主题、每套两种模式」。用户会尽力实现，但不能保证完成。
- 方案 B（备选）：如果第 2 步无法交付，先映射到现有 Token，并在本文逐项写明降级。三套主题的差异会部分或全部丢失；启用前须由用户确认降级范围，并重新批准受影响的视觉方向与页面契约。

页面契约按方案 A 起草；只依赖主题包的部分在契约中标明，以便切换到方案 B 时能定位影响范围。

## 页面设计状态

产品基线批准后，页面契约按以下批次起草与批准：

| 批次 | 页面 | 页面设计状态 |
| --- | --- | --- |
| 1 | 启动页、专注（含三种模式、休息、完成、放弃、中断恢复） | draft |
| 2 | 打卡、习惯详情、新建或编辑习惯 | draft |
| 3 | 回顾、设置（含表盘选择） | draft |

## 假设

以下细节由 Agent 推断，用户批准本文即视为同意；如需修改，在批准前指出：

- 默认表盘为机械；
- 提前结束或停止时不足 1 分钟视为放弃，不生成记录；
- 计圈只保存在当前会话中；
- 不支持补卡；
- 每周 N 次的习惯达到 N 次后仍可打卡；
- 已完成的打卡再点一次即取消，并可撤销；
- 归档的习惯在打卡页底部的已归档列表中查看与恢复；
- 提醒只保存时间并显示在习惯信息中，不发送通知；
- 设置只从专注页进入。

## 已否决方向

- 只用 PBWork 现有 DS 与主题的外观（曾作为草稿 B，已移除）；
- 只提供一个品牌色并允许用户自选主题色；
- 打卡页布局随表盘变化；
- 拖动表盘设置时长；
- 计时单独占一个底部 Tab，或四个以上底部 Tab；
- 连续天数、徽章、排行榜等制造压力的激励；
- 回顾作为数据分析报表。

## 未决项

- Flutter 交付约束：大概率交付到现有 Flutter App。本轮不处理交付端；需在 Target 还原前确认是哪个 App，以及它的主题、组件与路由约定，产品定义与旅程不受影响；
- 品牌层缺口最终走方案 A 还是方案 B（见上文），取决于平台升级第 2 步能否交付。

## 产品级验收信号

- 专注、打卡、回顾能分别用一句不重叠的话解释，每个根页面首屏只有一个最高视觉焦点。
- 打开应用后一次点击即可开始专注；暂停与继续、放弃与提前结束的结果不同且可见。
- 番茄完成一轮后进入休息，第 4 轮后进入长休；正计时可以计圈；倒计时到点有明确的可见反馈。
- 刷新或中断后回到同一会话，时间没有在后台增长。
- 打卡一次点击完成，可以撤销；打卡与专注完成后，回顾立即变化。
- 在设置中切换表盘后，所有页面立即换上该表盘的配色与签名图形，结构与阅读顺序不变。
- 三套主题的浅色、深色与跟随系统下层级、对比度一致。
