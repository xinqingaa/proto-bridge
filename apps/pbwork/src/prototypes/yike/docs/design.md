> 本文是一刻的产品与体验唯一基线。产品基线于 2026-10-16 批准；2026-10-18 用户确认后台继续计时、零历史并预置可删除习惯、倒计时追加合并记录，并授权 Agent 按既定产品边界闭合页面契约。本次契约依据该授权形成，沿用已批准视觉方向；页面设计批准不代表页面已实现或体验已验收。

## 原型实施边界（2026-10-19 用户确认）

本轮制作遵循[原型业务实现尺度](../../../../docs/principles.md#9-原型业务实现尺度)：数据流程、逻辑流转、页面交互和关键流程只需适配原型，可演示、可流转、关键操作结果一致；不追求完整真实业务。下文业务规则表达演示时应呈现的体验，本节优先约束其实现深度与验收范围，不要求全部转化为生产级保障。

- 实际运行支持演示期间的计时与状态流转。到点/休息等长等待可通过明确的演示场景或可控时钟验证；不要求真实等待完整周期。不把长时间后台、关页重开、时区变化、换日撤销等罕见组合的可靠性作为本轮退出条件；已有能力保留。
- 提醒与提示音可展示配置及即时反馈，不要求系统通知、权限和后台调度；外部能力未实际执行时不得显示已经执行成功。
- 空态、字段校验、取消、危险确认、关键成功反馈必须可演示；存储损坏/持续失败等异常按需要提供展示场景，不为此建立完整恢复系统。

正式页面的视觉、共享交互机制、可访问性与Evidence要求保持；模拟范围和实际验证结果记录在implementation.md，不将可演示原型描述为完整业务产品。

## 产品定义

**一刻**是一款只在本机运行的专注与习惯小工具：打开就能开始一段专注，一次点击完成今天的打卡，回头能看见时间花在了哪里。

它优先解决三件事：开始专注的门槛高、小习惯坚持不下来、过后说不清时间去了哪里。它不是任务管理工具，也不是数据分析工具。

### 用户与情境

- 用番茄钟切分工作、学习时间的上班族、学生与备考人群；
- 想坚持几个小习惯（喝水、阅读、运动、早睡），但不想被复杂的习惯工具打扰的人；
- 偶尔需要正计时计圈，或倒计时煮面、做平板支撑的人；
- 用户本人的日常使用。

### 产品承诺

任何时候打开一刻，首屏都能直接开始一段专注；完成的专注和打卡立即出现在回顾里。

### 设计原则

1. **打开即用**：没有登录、引导页或空白配置页；默认配置就能用。
2. **数字是主角**：计时数字是专注页唯一焦点，其它信息退为上下文。
3. **一次点击完成**：打卡一次点击完成，并且可以撤销。
4. **会话连续**：App 内导航和切到后台继续计时；刷新或关闭后可从已保存进度恢复，不把关闭期间计入时长。
5. **安静克制**：不用连续天数警告、徽章墙或羞耻文案制造压力。
6. **像一件物件**：每种表盘都像桌上一件真实的计时器，而不是一块仪表盘。

### 非目标

- 不做登录、账号、云同步、服务端或社交；
- 不做真实系统通知、系统后台服务或关闭应用后的持续计时；后台期间仍按实际经过时间计时，回到前台校准。提示音、振动和提醒只声明为交互意图，原型中以可见反馈代替；
- 不做白噪音、任务管理、日历同步或数据分析报表；
- 不做补卡：打卡只针对今天；
- 不做连续天数、排行榜或成就徽章。

## 核心对象

| 对象 | 作用 | 关键状态 |
| --- | --- | --- |
| 专注会话 | 一次番茄、正计时或倒计时 | 未开始、进行中、暂停、休息中、本轮完成、到点、已放弃、中断待恢复 |
| 番茄配置 | 专注时长、短休、长休、长休间隔 | 默认 25 / 5 / 15 分钟、每 4 轮长休 |
| 计圈 | 正计时中的分段 | 每圈用时、累计用时；只属于当前会话 |
| 专注记录 | 回顾的事实来源之一 | 开始时间、类型、有效计时秒数及日期分配；可在回顾中查看 |
| 习惯 | 名称、图标、频率（每天，或每周 N 次）、可选提醒时间 | 进行中、已归档 |
| 打卡记录 | 某天完成某个习惯，回顾的另一个事实来源 | 已打卡、已撤销 |
| 偏好 | 表盘、模式、番茄配置、提示音 | 立即生效并保存在本机 |

关系与规则：

- 完成的番茄轮、提前结束的番茄轮、停止的正计时、到点或暂停后提前结束的倒计时各生成一条专注记录；同一会话只记一次。放弃和初始倒计时取消不生成记录；倒计时追加后的记录规则见「记录与日期口径」。
- 提前结束或停止时，少于设置的短时记录确认阈值先通过Confirm询问；仍然记录则保存实际秒数，取消保留会话。达到阈值直接记录。
- 计圈只在当前会话中显示，记录只保存总时长。
- 休息不生成专注记录。
- 打卡只针对今天；每周 N 次的习惯达到 N 次后仍可继续打卡，进度显示为已完成。
- 归档的习惯从打卡页隐藏，记录保留，可以恢复；删除会同时删除其打卡记录。
- 「今天已专注」和回顾全部从专注记录与打卡记录派生，不另存统计值。

## 信息架构

### 根导航

底部导航始终只有三个根目的地，标签只用文字：

| 页面 | 唯一职责 | 明确不承载 |
| --- | --- | --- |
| 专注 | 开始并完成一段专注 | 习惯管理、历史分析 |
| 打卡 | 完成今天的习惯 | 计时、长期统计 |
| 回顾 | 看最近一段时间花在了哪里 | 编辑记录、管理习惯 |

正计时和倒计时是专注页内的模式，不单独占一个 Tab。设置是全局工具，不是根目的地，只从专注页工具行进入。

### 页面地图

| 页面 | 存在的理由 | 进入方式 |
| --- | --- | --- |
| 启动页 | 冷启动时建立品牌识别，然后让路 | 冷启动；结束后替换为专注页，返回不会回到启动页 |
| 专注 | 开始并完成一段专注 | 根 Tab；冷启动默认页 |
| 打卡 | 完成今天的习惯 | 根 Tab |
| 回顾 | 看一周或一个月的专注与打卡 | 根 Tab |
| 习惯详情 | 看一个习惯一年来的坚持情况并管理它 | 打卡页点习惯名称区域 |
| 新建或编辑习惯 | 用最少步骤建立或修改一个习惯 | 打卡页右上角新建；详情页编辑；以 FlowSheet 呈现 |
| 设置 | 选择表盘，调整模式、番茄时长和提示音 | 专注页工具行 |

任务型浮层：放弃确认、中断恢复、删除习惯确认、重置数据确认、时长选择、已归档习惯列表、打卡撤销提示。

### 导航规则

- 三个根页面只通过底部导航互相切换，内容区不跨根跳转。
- 习惯详情与设置是压栈页面，返回回到进入前页面和局部状态。
- FlowSheet 关闭只丢弃未保存输入；保存后回到来源页并显示结果。
- 回顾页的周、月切换和前后翻页改变可见数据，不只改变选中样式。
- 计时进行中切换 Tab 不中断计时；回到专注页看到同一会话。

## 核心旅程

### 打开即专注

首次冷启动显示机械表盘的品牌静帧，随后替换为专注页的「番茄 · 第 1 轮 · 待开始」。以后冷启动使用已保存表盘，有未结束会话时优先恢复。一次点击「开始专注」进入进行中。进行中可以暂停与继续；暂停时表盘图形明确静止。一轮结束后显示「本轮完成」，用户开始休息或跳过休息；每完成 4 个完整番茄轮提供长休。休息结束或跳过后停在下一轮待开始，不自动开始专注。

### 提前结束与放弃

进行中的次操作是「放弃本轮」，确认后不生成记录；确认中说明已专注的分钟不会记录，并给出保留的办法。暂停时的次操作是「提前结束并记录」，生成实际分钟的记录。

### 正计时与计圈

正计时从零开始，主操作为暂停与继续，次操作为计圈。计圈列表把当前圈放在最上方，已完成的圈显示单圈与累计用时。停止后生成总时长的记录。

### 倒计时

用户从预设时长中选择，或自定义时长，然后开始。进行中可以暂停或取消；到点后给出明确的可见反馈（提示音开启时同时声明提示音意图），用户选择完成或再计 1 分钟。追加可重复，均属于同一会话，不新增专注次数。

### 中断后恢复

App 内切换 Tab、打开设置、切到其他应用或浏览器后台均继续计时；返回时校准实际经过时间，已经到点则显示对应完成状态，超出的时间不自动推进到下一阶段。后台不要求持续播放动效或即时发出通知。

刷新或关闭后重新打开与后台返回不同：从最后保存的进度恢复为暂停，并优先显示恢复面板；关闭期间冻结。用户可以继续、结束并记录，或放弃；休息只提供继续与跳过，不记录。原本已暂停的会话保持暂停，不重复提示；本轮完成或倒计时到点保持原结果，不重新计时。意外终止最多恢复到最后保存点，不承诺恢复未保存的最后瞬间。

### 打卡与撤销

打卡页列出进行中的习惯，每个习惯显示本周七天的孔位与今天的打卡按钮。点一次完成今天的打卡，孔位与本周进度立即变化，并出现带「撤销」的短提示；再次点已完成的按钮取消今天的打卡，同样可以撤销。全部完成时页面给出一句安静的完成说明。

### 新建与管理习惯

打卡页右上角打开新建 FlowSheet：名称、图标、频率（每天或每周 N 次）、可选提醒时间。名称为空不能保存，错误就近说明。保存后回到打卡页，新习惯出现在列表中。习惯详情显示本周、本月、一年的完成次数与一年热力图，可以编辑、归档或删除；删除先确认。

### 回顾

回顾默认显示本周：专注总时长、专注次数、打卡次数，每天的专注分钟和按类型的分布。选中某天显示当天的专注记录与完成的习惯。切到月视图显示整月日历，每天的深浅表示专注分钟。没有记录时说明原因，并用文字提示从底部「专注」或「打卡」开始，不增加内容区跨根跳转按钮。仅有打卡时仍展示真实打卡结果，不把整页视为无数据。

### 切换表盘与模式

设置页的表盘选择以三张小预览呈现三种表盘各自的样子；选中后整个一刻立即切换配色与签名图形，打卡页布局不变。模式在浅色、深色与跟随系统之间切换，与表盘独立。

## 产品级体验规则

### 热区与反馈

- 看起来能点的元素必须有可观察结果和可见反馈；表盘图形只显示时间，不可拖动或点按设置时长。
- 同屏只有一个最高强调动作：专注页是开始、暂停或继续；打卡页没有全局主操作，每个习惯的打卡按钮各自独立。
- 打卡行中，名称区域进入详情，打卡按钮完成打卡，两个热区结果不同且互不误触。
- 内容本身的变化是成功证据，短提示只作补充。
- 放弃、删除、重置先确认；打卡变化以短时撤销代替确认。

### 计时规则

- 计时数字使用等宽数字，跳动时不左右抖动。
- 剩余时间同时由数字和表盘图形表达，两者始终一致：机械的扇面、水位的水面、日影的影子都按剩余比例变化；机械表盘按真实 60 分钟刻度读数。
- 暂停、休息、本轮完成、到点各有可区分的表达，不只依赖颜色：说明文字随状态变化，图形静止或变浅。
- 休息使用降低强调的同一图形，不引入第二个品牌色。

### 会话转换与配置

- 同时最多一个未结束计时会话；进行中或暂停时切换计时模式，先选择结束并记录或放弃，取消则保留原会话。休息中切换先确认跳过休息；本轮完成先选择休息或跳过，倒计时到点先完成或追加，不能静默清除结果。
- 番茄、倒计时运行时主操作为暂停；正计时运行时主操作为暂停、次操作为计圈。暂停后可继续或结束；番茄提前结束记录实际用时，不计入完整轮数，也不触发休息，返回当前轮待开始。
- 完整轮数按本次番茄周期累计；短休后进入下一轮，长休后从第 1 轮重新开始。放弃、提前结束、切换模式或跨日不伪造已完成轮数；切换模式保留番茄周期进度，重置数据才清空。
- 每个阶段开始时固定其时长及本轮应进入的休息类型。设置修改只影响尚未开始的阶段；当前阶段进度、已完成轮数不变。修改长休间隔时，不回头重算已完成的休息决策。
- 番茄专注时长为 1–180 分钟，短休和长休为 1–60 分钟，长休间隔为 2–8 轮；倒计时预设 3 / 5 / 10 / 20 分钟，自定义为 1 分钟至 23 小时 59 分钟，零时长不可开始。这些范围为本次授权内的产品细节。
- 正计时从零累加；达到一小时后显示小时位，暂停不计入时长。计圈仅在进行中可用，保留当前圈与所有已完成圈的单圈、累计用时；停止后只保留会话总时长。
- 机械表盘始终采用真实 60 分钟刻度。超过一小时，数字显示完整时长，扇面表达当前不足或等于一小时的部分，并以「另有 N 小时」或「已满 N 小时」文字补齐；整小时边界显示满圈且不误示为零。水位与日影的定时模式按本阶段总时长表达比例；正计时按当前小时内进度循环并显示已满小时数。三套主题的信息量相同。

### 记录与日期口径

- 保存实际有效计时秒数；暂停、关闭后的冻结时间、到点后等待操作的时间及休息不计入。列表与汇总先合计秒数再向下取整为分钟，不能逐条舍入后相加；有秒数但不足一分钟时显示实际秒数（可保留小数），不误示为无记录。
- 三种专注模式的主动结束、恢复面板结束、结束并切模式和自动到点，实际时长少于设置阈值时先通过Confirm询问是否记录；确认仍可保存短记录，取消保留当前会话和进度。达到阈值直接记录，阈值不再是拒绝记录的最低时长。默认10秒，预设5秒、10秒、1分钟、3分钟、5分钟、10分钟，另可自定义整数秒数（1–86399秒）；设置立即用于后续记录决定，不改变计时目标和经过时间。已有记录的倒计时追加不重复询问、不拆分次数；休息不入账。放弃另行确认。完成状态与保存结果必须能区分，不能仅以短提示代表完成。
- 倒计时首次到点在达到阈值或用户确认短时记录后，在回顾中出现一条记录；选择「再计 1 分钟」继续同一会话。后续到点、主动完成或取消追加，只更新这一条记录的实际有效总时长。取消追加保留已完成时长和追加中实际经过的时间，先说明并确认，不删除原记录；刷新或重复点击不重复记账。
- 到点后「完成」结束会话，回到原时长待开始；开始下一次倒计时才创建新会话。运行时长不能因后台校准而超出当前阶段目标；后台越过多个阶段也只结束当前阶段。
- 交互使用设备本地日期，周一至周日为一周，月按自然月，习惯一年为截至今天的最近 365 个自然日。打卡以操作当日本地日期为准，跨午夜自动切换今天；未来日期不可打卡、不可选为回顾明细，也不能翻到未来周期。
- 跨午夜的专注记录仍是一条会话，按实际发生日期分配有效秒数；每天和周期的专注次数按有有效时长的独立会话去重，跨日会话在当天可各计一次，在覆盖两天的同一周期只计一次。记录显示原始开始时间与当日分配用时，避免把整段重复累加；会话保存各有效区间当时的本地日期，之后切换时区不重写历史归属。
- 习惯每个自然日最多一条有效打卡。名称、图标、频率修改不改变已有打卡事实；新频率立即影响今天与本周目标，历史次数和热力图保留，不按新目标重算历史达标率。每日频率的本周目标为本周截至今天、创建日之后且未归档的天数，周频率显示本周实际次数 / 当前目标；达到目标后不限制继续打卡。
- 归档只停止打卡入口，归档前后的历史记录仍在回顾中；恢复不补卡。删除习惯及其记录后相关统计立即扣除。撤销只反转对应习惯当日的最近一次操作，连续操作以最新提示为准；换日后旧撤销失效，避免变相补卡。

### 首次使用与本机保存

- 首次使用为零历史、第 1 轮、机械表盘、跟随系统、默认番茄配置、提示音开启；预置「喝够 8 杯水」「读 20 页书」「跑步」「23 点前睡」四个可编辑、可归档、可删除的习惯，「跑步」为每周 3 次，其余为每天；所有提醒默认关闭，全部未打卡。
- 上述习惯只在首次初始化创建，用户删空后不自动补回；重置数据后历史、习惯、当前会话及偏好清空，恢复首次使用状态并重新创建预置习惯。重置确认明确告知这一结果。
- 演示期间的偏好、习惯、打卡、专注记录、轮次与当前会话使用共享状态，并复用已有轻量本地保存。失败/恢复展示遵守原型实施边界：未保存时不谎称已保存；可通过确定性场景展示「暂未保存，关闭后可能丢失」或恢复说明，不要求完整重试、迁移和损坏修复系统。

### 视觉命题

一刻像桌上一件安静的计时器物件。三种表盘是三件不同的物件：拧发条的厨房计时器、一杯慢慢喝掉的水、午后纸面上移动的日影。用户选择自己喜欢的那一件，整个 App 随之换上它的材质和语气。

### 三套表盘主题

| 表盘 | 物件与命题 | 品牌色与底色 | 签名图形 | 打卡标记 |
| --- | --- | --- | --- | --- |
| 机械 | 拧发条的厨房计时器，剩余时间是一块会变小的扇面 | 柿子色；哑光瓷白底 | 带 60 分钟刻度的扇面表盘 | 在本周那一格打一个孔 |

| 日影 | 午后纸面上的日晷，剩余时间是一道慢慢扫过的软影 | 靛蓝；暖灰纸底 | 纸面日晷上的软影 | 盖一枚刻着习惯首字的印章 |

三套主题统一使用 PBWork 默认字体，字体不随表盘变化。三套主题的取值以 `drafts/yike/styles/` 风格草稿为参照，正式取值在主题包中定义并通过对比度校验。

2026-10-19 用户确认草稿是方向参照，允许按实际清晰度与可用性调整。正式资源保留三种物件和标记语言；统计图统一主题强调色，水位月历数字增加实色小底片。具体归并及主动差异见 [resources.md](./resources.md#资源归并与主动继承决定)，无需逐像素复制草稿。

### 共享视觉语法

- **结构不随表盘变化**：信息架构、页面结构、阅读顺序、交互与状态在三套主题中完全一致；表盘只改变配色、签名图形、打卡标记和数据图形的笔触。
- **专注页是一件物件**：签名图形是专注页唯一的大物件，数字在物件内部；模式、轮次和操作退为物件周围的上下文。
- **打卡页是一张打孔卡**：每个习惯一行，周历孔位与右侧打卡按钮对齐同一条星期表头；三套主题只换孔位与按钮的标记。
- **数据图形沿用物件语汇**：回顾周视图的每日柱、月视图日历和习惯一年热力图都使用当前表盘的语汇：机械是按番茄块堆叠的柱与深浅圆形日期标记，水位是试管与小杯水位，日影是墨线软影与靛蓝印点。
- **工具页安静**：设置、习惯详情和新建习惯使用分组列表与表单，不出现签名图形，只在表盘选择中出现三张预览。

### 玻璃容器与三主题（2026-10-18 用户批准）

机械、水位、日影各自保留浅深模式，共六种组合。三套共用页面结构、交互与玻璃容器语言，机械使用边缘清晰的中性玻璃，水位使用微绿圆润玻璃，日影使用克制的暖灰/墨色玻璃；字体族不变，保留各自字重与适度字距。表盘、打卡标记与数据图形继续保留物件辨识度。

根导航、顶部模式/范围切换、设置分组与归档列表、打卡行、当天记录与详情概况、编辑/配置/确认面板使用玻璃容器；按钮与浮动操作按层级使用玻璃。页面背景和表盘/图形绘图区保留主题材质，同一区域避免多层玻璃叠套。文字、输入和危险动作始终清晰；减少透明度或无模糊支持时使用实色表面。

这是对草稿容器与导航材质的明确调整；其余产品契约、三套签名与页面阅读顺序继续有效。

2026-10-19 范围收敛：当前以已完成的 Tabbar、Tab/局部切换、Button 与 BottomSheet 等少量样例观察效果；已做好的其它适配保留，不撤回。上述更多容器区域作为候选，后续按实际页面效果决定，不要求全面铺设玻璃，也不以剩余玻璃适配阻塞资源和页面主线。当前制作精力优先三主题表盘、打孔卡和日期图形。

### 动效、声音与资产

- 进行中：机械扇面连续缩小；水面以很慢的波纹下降；日影缓慢扫过纸面。暂停时三者完全静止。
- 本轮完成与到点：一次短促的完成反馈；提示音开启时声明提示音意图，原型中以可见反馈代替。
- 打卡：机械打孔、水滴落下、印章盖下各有一次短反馈；撤销反向恢复。
- 减少动态效果时去掉波纹、扫动和打卡动画，直接切换到结果状态，信息与操作结果完整。
- 签名图形在正式实现中以 SVG 或绘制实现，不依赖位图；需要循环动效的水面波纹单独声明资产与降级。

- 首要验收视口为 `390 × 844`，常见窄屏不得横向溢出。
- 页面只消费一次顶部安全区域，内容不被底部导航遮挡。
- 键盘弹出时，当前字段与保存操作可以滚动到可见位置。
- 可交互元素具备可读名称、完整触控区域和可见键盘焦点；签名图形提供与数字一致的可读描述。
- 三套主题的浅色与深色都保持相同的语义层级和对比关系；日影深色中的影子改为浅色光晕，保证可读。

### 内容语气

- 短句、具体、安静，例如「今天已专注 50 分钟」「第 3 轮已完成 · 休息一下」「从一个小习惯开始」。
- 不催促、不评判：中断与放弃使用中性说明，例如「已经专注的 12 分钟不会被记录」。
- 数字结论说明时间范围，例如「本周」「10月14日 周三」。

## 页面契约

以下契约共同遵守「会话转换与配置」「记录与日期口径」「首次使用与本机保存」，不以静态草稿中的数字作为真实初始值。三套主题共享行为、阅读顺序和状态；草稿未展示的状态按相同视觉语法补齐。

### 启动页

- **职责与首屏焦点**：建立一次品牌识别后立即让路，焦点为当前表盘的品牌静帧。
- **阅读顺序**：品牌物件 → 一刻名称 → 简短产品承诺；不显示历史统计或操作。
- **热区与结果**：无伪装为按钮的热区，无登录、欢迎确认或必须点击才能进入的步骤；完成必要本机读取后进入专注。减少动态效果直接进入，品牌不增加额外等待。
- **状态**：首次机械主题、以后按偏好主题、浅深模式、减少动态效果；存在待恢复会话时进入恢复状态，本机数据损坏时进入明确恢复说明。
- **跨页分工**：仅冷启动出现；从后台返回或根页面切换不重复启动，返回不会回到启动页。
- **验收信号**：首次进入后可一次点击开始第 1 轮；三套主题都能识别品牌；有待恢复会话不被新会话覆盖。

### 专注

- **职责与首屏焦点**：开始、控制并结束一个会话，数字与物件表盘为唯一最高视觉焦点。
- **阅读顺序**：日期与今天已专注、设置入口 → 模式 → 表盘数字和状态 → 轮次或当前圈上下文 → 主次操作 → 根导航。正计时圈列表、倒计时预设属于当前模式上下文，不抢过数字焦点。
- **热区与结果**：模式选择遵循未结束会话确认；表盘仅展示。开始进入运行，暂停冻结，继续恢复，放弃先说明不记录并确认；暂停时提前结束记录并返回当前轮待开始。完整番茄结束提供开始对应休息、跳过休息；休息可暂停、继续、跳过，到点等待用户开始下一轮。正计时进行中可计圈，暂停后可停止并记录。倒计时待开始可选预设或自定义、运行中可暂停或取消、暂停后可继续或结束并记录、到点可完成或追加一分钟。
- **恢复面板**：只针对刷新或关闭造成的未结束运行阶段；继续、结束并记录或放弃，按阶段替换为适用操作。关闭面板保留暂停会话，页面给出「查看恢复选项」入口，不自动继续、不丢失进度。
- **状态**：番茄待开始、运行、暂停、短休和长休的运行/暂停/结束、本轮完成、放弃确认；正计时待开始、运行无圈/有圈、暂停；倒计时设置、运行、暂停、到点、追加、取消确认；模式切换确认、短时记录确认、中断恢复、保存失败。空历史时今天为零。
- **跨页分工**：Tab 和设置不停止计时；返回保留同一会话和圈列表。只负责当前会话，已完成事实由回顾展示，设置管理后续配置。
- **验收信号**：开始一次即可运行；暂停时数字和图形同时静止；后台返回的数字与实际经过时间一致；后台越过到点不自动开始休息或下一轮；刷新恢复不补计关闭时间。完成与放弃对回顾的结果不同，追加多次始终只有一条记录。三套表盘在零、整小时和超过一小时都不误读。

### 打卡

- **职责与首屏焦点**：完成今天的习惯，焦点为可操作的习惯打孔卡列表和今天完成情况。
- **阅读顺序**：标题、今天完成数与新建入口 → 共用星期表头 → 习惯行（名称、频率、本周孔位、今天按钮） → 完成或空态说明 → 已归档入口 → 根导航。
- **热区与结果**：名称区域进入详情，今天按钮切换当日打卡状态；孔位只表示记录，不允许补卡。每次操作立即更新孔位、次数和回顾，并提供对应撤销提示；提示在未替换、未换日的短时间内可撤销。新建打开表单；已归档入口打开列表，可查看详情或恢复，关闭留在打卡页。
- **状态**：首次预置但全部未完成、部分完成、全部完成、没有进行中习惯、只有归档习惯、归档列表空/非空、打卡与取消后的撤销提示、周目标已达仍可打卡、换日、保存失败。全部完成只按今天逐项已打卡判断，不把已达周目标的未打卡项自动算成今天完成。
- **跨页分工**：详情负责查看和管理单个习惯；打卡页保留列表位置；表单保存后新增行立即可见，归档/删除后移除相应行，恢复后返回进行中列表。
- **验收信号**：一次点击完成且可撤销；名称与按钮互不误触；删除所有习惯后不偷偷重建预置项；已归档记录不丢失，恢复不产生今天打卡；三套主题只改变标记与配色，行的阅读顺序不变。

### 习惯详情

- **职责与首屏焦点**：理解一个习惯的坚持情况并管理它，焦点为习惯名称、频率和真实完成概况。
- **阅读顺序**：返回与编辑 → 名称、图标、频率和可选提醒 → 本周、本月、最近一年次数 → 周目标上下文（适用时） → 最近一年热力图 → 归档/恢复与删除。
- **热区与结果**：返回原打卡列表；编辑打开已有值的表单。热力图是有可读日期与完成状态的展示，不伪装成补卡入口。归档保留记录并回到打卡页；已归档详情明确状态并可恢复。删除先说明习惯及全部打卡记录不可恢复，确认后返回来源，取消保留详情。
- **状态**：每日/每周目标、零记录、有记录、创建不足一年、已归档、删除确认、编辑保存后、保存失败；创建前、归档期间未打卡及未来日期有可区分说明，不虚构历史。
- **跨页分工**：详情不编辑历史，不控制计时；编辑取消保留原值，保存留在详情并同步打卡与回顾。深链对象不存在时显示说明与返回打卡入口，不能展示别的习惯。
- **验收信号**：概况与实际打卡日期一致；零历史无随机热力数据；频率修改保留历史事实；归档可恢复，删除确认内容与实际扣除范围一致。

### 新建或编辑习惯

- **职责与首屏焦点**：用最少输入建立或修改习惯，焦点为名称字段与保存结果。
- **阅读顺序**：标题与关闭 → 名称及就近错误 → 图标 → 频率与每周次数 → 可选提醒和时间 → 保存。
- **热区与结果**：新建默认空名称、叶子图标、每天、提醒关闭；编辑填入当前值。名称去除首尾空白后须为 1–30 个可见字符，重复名称允许但记录互相独立；可选叶子、书、水杯、脚步、月亮、拉伸。周次数为 1–7；提醒开启后可选本地时间，仅保存并显示，不发送通知。保存只提交一次；关闭、返回或下滑关闭丢弃未保存输入，不修改已有习惯。
- **状态**：新建、编辑、每日、每周次数、提醒开/关与时间选择、空名称/超长错误、保存成功、保存失败。未通过校验不能保存；尝试提交时在字段旁说明原因，修正后即时消失。
- **跨页分工**：新建成功回打卡并显示新习惯；编辑成功回详情。键盘打开时当前字段和保存可滚动到可见；关闭键盘不丢输入，切换频率不清空名称。恢复归档不由此表单隐式执行。
- **验收信号**：空白名称不能生成习惯；有效保存后关闭表单且来源内容变化；双击保存不重复创建；取消不污染原值；关闭后重开新建使用默认空表单。

### 回顾

- **职责与首屏焦点**：看所选周期真实发生的专注与打卡，焦点为带时间范围的总结与对应分布。
- **阅读顺序**：标题 → 周/月与周期前后切换 → 范围总计 → 每日图形 → 选中日明细（适用时）与类型分布 → 根导航。周汇总显示专注时长、专注次数、打卡次数；月汇总显示专注时长、专注天数、打卡次数。
- **热区与结果**：周/月切换展示真实对应周期；有选中日时以该日定位新周期，否则以当前周期起始日定位。上一周期可查看历史，下一周期最多回到本周/本月，历史不以是否存在记录或初始化日期为边界，无记录周期仍可翻阅并展示空态。点有效日期展示当天记录与完成习惯，再点同日收起；零记录日仍可选，未来禁用。切换周期清除旧选中日，切换 Tab 保留当前范围、选择和滚动。
- **状态**：周、月、选中日、整周期零记录、仅有打卡、仅有专注、选中日零记录、跨日会话、追加后的同一会话、未来日期禁用。全空说明如何通过底部导航开始；仅有打卡仍显示打卡结果，专注图形为零。
- **跨页分工**：不编辑记录、不管理习惯、不在内容区跨根跳转；完成记录、撤销打卡、归档和删除的结果立即反映。类型分布只统计有效专注时长，习惯不混入专注分钟。
- **验收信号**：周/月切换和翻页确实改变数据；总计与记录、日期分配一致；相同跨日会话不在周期中重复计数；月专注天数只计有有效专注时长的日期；三个主题均可读、可选，空态无样例数据填充。

### 设置

- **职责与首屏焦点**：选择物件与调整后续专注偏好，焦点为三种表盘预览和当前选择。
- **阅读顺序**：返回与标题 → 三种表盘预览 → 浅色/深色/跟随系统 → 番茄专注、短休、长休与间隔 → 短时记录确认阈值 → 提示音 → 重置数据与本机保存说明。
- **热区与结果**：表盘选择立即更新全 App 的配色与签名图形；模式选择独立生效，跟随系统响应系统变化。时长和间隔打开选择面板，确认应用、取消保留旧值；提示音开关只改变完成反馈意图。重置先明确清除会话、历史和用户习惯，恢复默认并重新预置四个习惯；确认后回专注第 1 轮待开始，取消留在设置。
- **状态**：三种表盘各自的浅深模式、跟随系统、每种选择面板、运行中修改配置、重置确认、保存失败。重置确认打开时不偷偷暂停，确认重置才清除会话。
- **跨页分工**：只从专注进入，返回原专注局部状态；会话仍继续。表盘和模式立即应用，时长修改遵循阶段开始时固定的规则，不让进行中的数字跳变。
- **验收信号**：选择表盘后所有页面的主题一致，打卡布局不变；模式与表盘相互独立并在重开后保留；运行中改时长不改变当前进度，后续阶段采用新配置；重置后不残留记录、计圈、轮次或旧偏好。
