# 一刻产品设计与交互

## 产品定位

一刻是本机使用的专注与习惯小工具：打开即可开始专注，一次点击完成今天的习惯，回顾时间和打卡的积累。面向学习、工作和日常习惯场景，整体安静、简洁，带有桌面计时器的实物感。

应用没有登录、云同步、社交、任务管理、排行榜或成就系统。提示音、振动和习惯提醒以配置及可见反馈表达，不发送系统通知，也不依赖系统后台服务。

## 页面与导航

| 页面 | 内容与入口 |
| --- | --- |
| 启动 | 当前主题的品牌静帧、名称与本机保存说明；冷启动后进入专注，不增加等待或确认步骤 |
| 专注 | 默认根页面，包含番茄钟、正计时、倒计时；右上角进入设置 |
| 打卡 | 进行中的习惯、本周进度与今天的打卡；新建入口和已归档习惯入口 |
| 回顾 | 周/月范围、总计、每日图形、按类型分布和日期明细 |
| 习惯详情 | 从习惯名称进入，查看完成情况，并编辑、归档或删除 |
| 新建或编辑习惯 | 覆盖来源页面的表单面板，保存后更新来源内容 |
| 设置 | 表盘、浅深模式、番茄配置、倒计时常用项、短时记录确认阈值、提示音与数据重置 |

底部导航以图标和文字呈现专注、打卡、回顾三个目的地。根页面切换保留各自局部状态；内容区不另设跨根页面的跳转入口。设置和详情返回原页面，表单及日期明细关闭后恢复来源页面的滚动与焦点。后台返回和页内导航不重复显示启动页。

## 专注

### 布局与操作

阅读顺序为日期与今日专注汇总、三个计时模式、表盘读数、轮次或计圈、主次操作、底部导航。表盘是主要视觉对象，数字清晰居中；表盘图形不可拖动，也不用于设置时长。

开始、暂停、继续和完成保持同一主操作位置，使用最高强调的胶囊按钮。暂停后提供继续与结束操作；放弃与结束并记录明确区分。状态说明位于表盘附近，不与次操作混排。正计时的计圈列表独立滚动，增加计圈不挤动表盘和主操作。

### 三种模式

| 模式 | 时长与图形 | 结束后的行为 |
| --- | --- | --- |
| 番茄钟 | 默认专注 25 分钟；短休 5 分钟、长休 15 分钟，每 4 个完整轮次长休。专注和休息一圈代表 60 分钟 | 完整轮次生成记录，可开始休息或跳过；休息结束停在下一轮待开始，不自动专注 |
| 正计时 | 从零累加，一圈代表 60 分钟，满圈回绕；运行时可计圈，暂停时间不计入 | 停止后保存本次有效总时长；计圈只保留在当前会话 |
| 倒计时 | 从常用项选择或自定义，范围为 1 秒至 23 小时 59 分 59 秒；一圈代表本次所选时长，从满到空 | 到点自动保存记录，显示完成；下方可按上一轮设定时长再计一次 |

番茄与正计时超过一小时后，数字显示完整时长，图形表达当前小时的比例，并通过“另有”或“已满”说明小时数；整小时边界显示满圈。倒计时始终按本次目标时长表达完整一圈，机械倒计时不显示分钟刻度数字。

运行读数使用分:秒，达到一小时后使用时:分:秒。时长选项和再计标签使用带单位的简写，如 45秒、5分、1分30秒、1小时30分，省略零值单位。同一会话跨过小时边界时保持读数字号稳定。

### 会话转换

同时最多一个未结束会话。运行中可以暂停，暂停后可以继续、结束并记录或取消。放弃需确认，确认后不保存本次未记录时长。

进行中或暂停时切换模式，先选择结束并记录或放弃；取消保留原会话。休息中切换需确认跳过休息。番茄完成态先选择休息或跳过，倒计时到点先完成或再计，结果不会因切换模式被静默清除。

完整番茄轮数按当前周期累计，短休后进入下一轮，长休结束后回到第 1 轮。提前结束的番茄记录实际用时，不计完整轮数，也不触发休息。每个阶段开始时固定目标时长和休息类型，设置修改只影响尚未开始的阶段。

倒计时再计按钮显示刚结束的目标时长，例如“再计5分”“再计1分30秒”。再计创建从零开始的独立会话，保留上一轮记录；等待操作的时间不计入，取消新一轮不影响上一轮。

### 后台与重开

切换应用内页面、打开设置或进入浏览器后台都继续计时，返回时按实际经过时间校准。到点只结束当前阶段，不自动跨越多个阶段。

刷新或关闭后重开，从最后保存点暂停恢复，不计关闭期间的时间。恢复面板可继续、结束并记录或放弃；休息只提供继续与跳过。原本已暂停的会话保持暂停，完成和到点状态保持原结果。

## 打卡与习惯

### 打卡页

标题与今日完成进度位于顶部，新建入口与之并列。每个习惯一行：名称和频率进入详情，本周七天的标记只读，今天的打卡按钮独立操作。

点击打卡立即更新今天的标记、本周进度和回顾，并显示带习惯名称的撤销提示；再次点击取消今天的打卡，也可撤销。提示不插入正文推动列表。全部完成时显示安静的完成说明。

只允许为今天打卡，每个习惯每个自然日最多一条有效记录，不提供补卡。每周目标完成后仍可继续打卡。

### 新建与编辑

表单包含名称、图标、每天或每周 N 次、可选提醒时间。名称去除首尾空白，必须包含可见内容，最多 30 个可见字素；提醒时间为合法的本地时分。每日频率不展示周次数输入；提醒关闭时隐藏时间选择。

错误在字段附近说明，合法输入后消失；保存中不能重复提交。取消只丢弃未保存内容，不污染原值。新建保存后回到打卡并显示新习惯，编辑保存后更新详情。面板覆盖真实来源页面，内容增长或键盘出现时仍能滚动到字段和保存操作。

### 详情与管理

习惯名称为主要标题，下方显示本周、本月、一年的完成次数与最近 365 个自然日的热力图。每日习惯的本周目标以创建后、截至今天且未归档的有效天数为分母；每周习惯显示实际次数与当前目标。

修改名称、图标、频率不改变已有打卡事实；新频率影响今天和本周目标，不重算历史完成记录。归档后从打卡列表隐藏，历史保留，可在已归档列表恢复，恢复不补卡。删除需确认，会同时删除该习惯的打卡记录。

## 回顾

### 范围与总计

默认显示本周，支持周、月切换和前后翻期；周一至周日为一周，月按自然月。历史周期连续可翻，不因没有记录而中断，不能进入未来周期。返回当前周期的入口不改变正文位置。

周总计显示专注时长、专注次数、打卡次数；月总计显示专注时长、专注天数、打卡次数。类型分布按番茄钟、正计时、倒计时列出次数和时长，使用同宽轨道比较，仅显示模式文字。

### 每日图形

周图以真实每日分钟数绘制，量程至少 125 分钟，较大记录会扩展量程并明确标注。机械使用分块柱、水位使用试管、日影使用墨线软影。

月历为七列紧凑日期。每日专注量分为低档（大于零且不超过 30 分钟）、中档（超过 30 且不超过 90 分钟）、高档（超过 90 分钟）；档位不随当月最大值重新缩放。

- 机械使用柿色圆形标记。
- 水位使用圆形杯壁，三档水高分别为 1/3、1/2、满杯；颜色浓度和高度分别表达，数字没有不透明底片，水面上下使用清晰的前景色。
- 日影使用方形印框与靛蓝软影，档位越高，影子浓度与模糊越深。

零记录和未来日期保持空图形。今天用上缘的纯图形指针标记：机械为短针、水位为水滴、日影为斜楔；今天数字加粗。选中描边沿图形边缘，不覆盖原有数据，键盘焦点单独表达。

### 日期明细

点击日期打开本周或本月的明细面板，再点同日可收起；空记录日可查看，未来日期不可选。面板先显示日期星期与当日合计，再按开始时间列出类型名称、有效时长及已完成习惯。模式仅显示文字。

前一天、后一天固定在底部，逐日移动并保留空日，不跨出打开时的周/月范围，也不进入未来。长记录列表由正文滚动，关闭与前后翻日操作始终可见。明细切日不推动来源页面。

切换周期清除旧选中日；切换周/月时以所选日定位，没有所选日则使用当前周期锚点。根导航切换保留回顾范围和局部状态。

### 空态与记录口径

没有任何记录时保留周期导航，说明可以从底部专注或打卡开始，不展示虚构历史或空的大图。仅有打卡时展示实际打卡结果，专注数据为零。

记录保存有效秒数，暂停、关闭后的冻结时间、到点后等待和休息不计入。提前结束或停止时，实际用时低于短时记录确认阈值会询问是否仍然记录；取消保留会话，确认保存实际秒数。完整倒计时到点直接记录。

周月概览先合计秒数再换算分钟；日期明细保留秒数，例如 1分35秒，整分钟不补零秒。跨午夜会话按实际发生的本地日期分配秒数；同一会话在覆盖多个日期的周期中只计一次专注次数，重复操作不重复入账。归档保留打卡历史，删除习惯移除对应打卡历史。

## 设置与本机数据

表盘以三张真实缩略预览选择，选中后所有页面立即使用同一套配色和图形。浅色、深色、跟随系统与表盘独立；跟随系统响应系统外观变化。

| 配置 | 默认值或范围 |
| --- | --- |
| 番茄专注 | 默认 25 分钟，范围 1–180 分钟 |
| 短休、长休 | 默认 5、15 分钟，范围各为 1–60 分钟 |
| 长休间隔 | 默认每 4 轮，范围 2–8 轮 |
| 常用倒计时 | 四个槽位，默认 3、5、10、20 分钟；可修改、清空、恢复默认，不接受重复或越界值 |
| 短时记录确认阈值 | 默认 10 秒；预设 5秒、10秒、1分钟、3分钟、5分钟、10分钟，或自定义 1–86399 秒 |
| 提示音 | 默认开启，以可见反馈表达完成提示 |

时长选择使用滚轮，倒计时和自定义阈值支持时、分、秒。确认应用，取消保留旧值。常用项中的空槽不在专注页出现，全部清空后只显示自定义；面板保留必要校验反馈，不显示重复的操作说明。分步面板的指示器位于内容下方、操作区上方，不随正文滚动。

首次使用没有专注或打卡历史，预置四个可编辑、可删除的习惯：喝够 8 杯水、读 20 页书、每周 3 次跑步、23 点前睡。初始表盘为机械，外观跟随系统。

数据和偏好保存在本机。保存失败时保留当前操作并提供重试；数据无法读取时明确提示，不用示例历史替代。重置前确认清除会话、历史、用户习惯与偏好；确认后恢复默认和四个初始习惯，回到专注第 1 轮待开始，取消保持原状态。

## 主题与视觉

三套主题共享页面结构、字体、业务与交互，表盘和配色作为一套选择。

| 主题 | 配色与材质 | 图形语言 |
| --- | --- | --- |
| 机械 | neutral 中性瓷白/石墨底，persimmon 柿色强调 | 清晰刻度与扇面；打孔、短条轮次、圆形日期 |
| 水位 | clear 中性清水玻璃，浅色石墨字、深色浅字，杯壁局部轻磨砂 | 水平水面与柔和反光；水滴轮次、小杯日期 |
| 日影 | 浅暖纸底与靛蓝，浅色背景 #EEEDE8；深色为墨灰 | 日晷软影与深色光晕；斜方轮次、方形印记 |

普通页面背景保持安静，强调色用于主操作、进度、今天与选中。根导航、局部切换和业务面板使用轻玻璃材质，避免重复叠套；降低透明度或不支持模糊时使用实色表面。危险操作有独立颜色和确认说明。

三种表盘保留完整物件比例和稳定位置，正计时不会缩成缩略图。计时数字使用等宽数字，长读数在中心安全区内，数字变化不左右抖动。普通图标为细线条，避免装饰性堆叠。

### 动效与反馈

运行图形按真实时间连续更新，保留每秒轻反馈、每分钟略重反馈和阶段结束的一次完成反馈；暂停静止。主读数只对变化位逐位翻动，递增向上、递减向下，冒号静止；后台恢复或大跨度变化短过渡到当前值，不补播秒数。水面上下两份读数同步。

按钮有按压、释放和标签过渡；模式切换保留方向连续的选中与内容过渡。打卡分别使用打孔、水滴或盖印的一次反馈。回顾翻期的日期与图形同向衔接，柱形不反复整组生长。普通正文和统计数字不逐位翻动。

减少动态效果时直接呈现最终状态，数字继续按时间更新，操作结果完整。

## 可访问性与文案

手机主要视口为 390 × 844，窄屏内容可滚动，不出现横向溢出。安全区只占用一次，内容不被底部导航或面板操作遮挡；键盘出现时字段和保存可达。页面隐藏滚动条，但保留触摸、滚轮和键盘滚动。

交互元素具备可读名称、充分触控区域和可见键盘焦点；表盘提供与数字一致的可读描述，水下重复读数不重复读屏。状态通过文字、形态和颜色共同表达，浅深模式保持清晰层级。

文案使用具体、简短、中性的说明，统计明确时间范围；不使用催促、评判或连续天数压力。放弃、删除、重置先说明结果再确认，打卡通过撤销恢复。
