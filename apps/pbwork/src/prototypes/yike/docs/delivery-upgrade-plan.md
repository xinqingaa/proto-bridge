## 文档补全清单

现有产品文档已详细覆盖核心业务、计时状态、习惯生命周期、统计口径、默认值和本地保存对象。本轮保留这些内容，只补缺失或含糊的规则。

| 维度 | 工作 |
| --- | --- |
| 逻辑与流程 | 核对番茄短/长休、主动结束、短记录确认、模式切换、再计和中断恢复；把冲突或未明确的边界单独列为待决事项 |
| 数据管理 | 明确保存触发点、保存失败后的反馈与重试、初始化/删空/重置区别、会话与历史的去重关系、日期分配和未保存进度边界 |
| UI | 按页面补主内容顺序、固定区与滚动所有者、面板正文与底部操作边界、窄屏与键盘行为；截图与主题数据仍是可见结果依据 |
| 交互 | 区分根导航、计时模式、详情进退、编辑面板和分步面板；核对取消、返回、快速连续操作和禁用状态 |
| 动效 | 在实施时新增 motion.md，记录触发、停止/重播、后台与大跨度更新、减少动态效果行为；引用公共 DS Contract 与采集片段，参数来源不手工漂移 |

文档接入时将 design.md 作为 required 产品说明；动效意图说明随正文固定。声明 Screen 与章节、动效片段的明确关联，不由 Agent 猜测标题对应关系。README 只做索引，不复制业务定义。

## 动效登记与验收矩阵

| 场景 | 需要观察的过程 | 关键检查点 |
| --- | --- | --- |
| 正计时与倒计时读数 | 单秒递增向上、递减向下；变化位翻动、冒号静止 | 单秒且长度不变；跨分钟；59:59 到 1:00:00；大跨度变化走短过渡而不补播 |
| 水位读数 | 水面上下两份读数在同一业务时刻更新 | 同步、反色、裁切；重复副本不重复读屏 |
| 机械表盘 | 连续比例变化、秒脉冲、分钟反馈 | 通过接近边界的 fixture 观察，暂停后停止反馈 |
| 水位表盘 | 水位变化、反光、分钟涟漪 | JS/SVG 过程采样可见；不能只记录 CSS 动画列表 |
| 日影表盘 | 阴影变化、秒明暗和分钟环 | 正常运行与暂停、完成、休息状态区分 |
| 阶段完成 | 一次完成反馈与结果文案过渡 | 到点、等待、完成与再计不重复结算；读数与结束图像一致 |
| 主操作 | 按下、释放、文字切换 | 开始/暂停/继续；按压不冒充 click；标签与业务状态一致 |
| 计时模式 | 选中态与内容过渡 | 无会话直接切换；有会话先确认；取消不丢会话 |
| 主题打卡 | 机械打孔、水滴下落、日影盖印 | 成功触发一次；取消/撤销与再次进入页面的重播规则明确 |
| 回顾 | 前后翻期方向、日期与图形衔接、周月变化、容器高度 | 图形不反复整组生长；日期明细不改变来源布局 |
| 导航 | 根页面内容切换、底部选中反馈、详情进入与返回 | 区分根内容即时切换与详情过渡；保留滚动和状态 |
| 面板 | 打开、关闭、分步前进与返回 | 关闭未确认草稿；确认保存；正文/操作区不跳动或失去可达性 |
| 减少动态效果 | 直接更新与持续计时 | 功能和结果保留，正常动效过程不能用此 profile 替代 |

三主题在图形和反馈不同的场景分别采集。共享的按钮、面板和导航机制复用 DS Contract，不对所有业务状态重复录制相同机制。浅深模式先完成静态回归，只有可见动效存在模式差异时扩展过程采集；390 × 844 为主要视口，窄屏补布局风险检查。

实现中对快速连续点击、返回或重开、后台恢复、动画中断存在不明确意图时，列出具体选择与影响后再确定基线；不以当前偶然 CSS 行为自动认定产品预期。

## 独立 yike 工程验证脚本

1. 用现有 Target 绑定流程核对 Workspace delivery 目标，再在独立 yike 工程调用 inspect_evidence_workspace，确认实际 Target Root；不通过复制 Evidence Store 解决连接。
2. 按既有生命周期执行定稿；若已有正式交付需要更新，走回退/重做，不直接改历史引用或生命周期 sidecar。
3. 仅把系统生成的固定交付提示词交给 Agent。Agent 读取工程规则与 Handoff，不额外获得产品文档正文或 Producer 源路径。
4. Agent 从文档目录读取初始化、记录结算、恢复规则与回顾统计章节；从 Screen 索引读取相关截图和动效片段。
5. Agent 返回产品理解摘要：一次跨日会话怎样入账、短记录与倒计时到点的区别、保存失败怎样反馈、正常/减少动态效果怎样不同，并引用固定文档章节和过程帧。
6. 修改或临时移走 Producer 的当前产品文档，仍能从同一 Handoff 读到原文旧版本；准备新的交付时能够检测摘要变化。
7. 验证数字翻动、JS/SVG 表盘、打卡和面板至少各一组过程帧；三主题差异按矩阵展开，required 片段失败时不能标为全部完成。
8. 本轮不自动实现 Target 业务。若后续实施，遵守独立工程编辑前的理解摘要与批准流程，再运行其原生验证；Source 采集完成不等于 Target 还原完成。
