# 当前实现限制

本页记录原型代码的当前限制，区分实现事实、产品要求和未验证结果。

## 保存失败仍可能提示成功

原型 createHabit 在写入失败后仍返回已创建的 ID；updateHabit 同样没有把 save() 失败传给页面。HabitEditor 据此提示“已保存”并关闭。内存操作成功与本地保存成功可能不一致。

当前编辑页不能可靠区分内存修改成功与持久化成功，也没有完整的失败保留和重试流程。

## 异常关闭后的进度损失

原型不逐秒保存，恢复只使用最后有效保存点。运行期间没有新的保存动作时，可能丢失整段尚未保存的有效用时；关闭期间不补时。当前逻辑已在 [保存与恢复限制](logic-and-interactions.md#实际保存触发点与恢复限制) 明确。

当前恢复以最后有效保存点为准，不保证后台持续执行。

## Flutter 业务存储尚未建立

当前 Flutter `lib/features/` 为空，AppPrefs 只登记主题偏好，工程架构明确不以现有偏好接口直接存业务数据。业务持久化对象和产品要求已经写入逻辑文档，但具体存储接口、序列化、迁移、故障返回和测试替身尚未实现。

Target 的业务持久化尚未建立；本页不声明新增存储接口或 key。

## 动效过程与视觉尚未验收

已整理数字、三表盘、打卡、回顾、导航及面板的动效意图。当前 Capture 使用减少动态效果并清零 CSS 动画/过渡时长，没有正式时间轴或过程帧交付。

正常动效的中断、重播、快速连续操作和后台恢复没有正式过程证据。当前没有正式的录屏、动效采样、自动评分或 MCP 动效工具。

## 资源精确复用的边界

Flutter 已有 DS 生成的 PNG 与清单；采集输出的资源声明与截图用于确认实际使用。通用逐资产 resolver、图标逐项摘要和 Target 本次真实使用的自动校验仍未建设。

遇到资源缺失、清单漂移或与固定 Evidence 摘要不符，应报告并处理对应 DS 版本，不静默替换成相似图或重绘。引用交付不承诺历史 SVG 原稿都可离线取回；历史归档 Blob 按原固定引用继续读取。

## 文档交付与 Evidence 的版本关系

产品文档在本目录维护。当前脚手架不自动复制原型文档，Target 本地副本通过手工复制提供，已有工程文档不被覆盖。

产品说明、逻辑与交互、UI 与动效、已知缺口四份文档使用同目录相对链接，便于作为一组同步；不依赖目标工程反向读取 Producer 文件，也不通过 MCP 分发产品文档。复制品不自动与 Handoff 绑定，本文也不是固定 Evidence。

交付时核对文档来源与版本，发现文档要求与固定 Case/Screenshot 冲突时记录双方来源。不得通过读取 Producer 当前文件或 active/latest 来替换固定 Evidence。

## 提醒与提示音

原型保存提醒开关、时间和提示音偏好，但不实际调度系统通知或播放完成声音。当前没有系统通知与声音播放能力。
