# Evidence fixtures

`reference-case-slice` is the **only** golden vertical slice for Core Evidence
contracts, Store, Handoff, and MCP/Consumer scripts.

- Export: `fixtures.referenceCaseSlice`
- IDs such as `sample` / `sample.task-list` are synthetic and intentionally not
  tied to a live PBWork prototype.
- **Do not** add `fixtures/<prototype>-*` directories when shipping a new app.
  See [PBWork 开发规范 · 新原型与测试边界](../../../../docs/pbwork/development.md).
