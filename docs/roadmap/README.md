# 平台升级记录

平台规划面向所有原型，不包含具体业务原型的设计、制作排期或验收进度。

目前保留[PBWork 与 PB 平台关键升级](../history/pbwork-platform-upgrade.md)，记录当时确定并完成的六项投入：

1. 采集可靠性收口。
2. 原型主题包。
3. 采集质量与固定取值。
4. 制作工具与共享运行能力。
5. DS 通用组件。
6. 设计基础与组件预览工作流。

上述升级已完成。现行规则查 Product、Architecture、Reference 和 PBWork 手册；新平台提案不以某个业务原型的制作进度作为平台完成状态。
